# HOMEZ Self Monitor

## 알림 형식

```
[HOMEZ <등급>]

버전:
Phase:
현재 작업:
확인 근거:
상태:
위험:
자동으로 계속할 작업:
보류한 작업:
다음 Gate:
```

## 위험 등급

- **INFO** — 정상적인 단계 완료 또는 상태 전환. 질문하지 않고 계속 진행한다.
- **NOTICE** — 사용자가 나중에 알아야 하지만 진행을 막지 않는 사항(개선 여지,
  선택적 후속 작업). 질문하지 않고 계속 진행한다.
- **WARNING** — 현재 작업은 계속할 수 있지만 릴리스 전 해결해야 하는 위험. 질문하지
  않고 안전한 범위의 작업을 계속하되 보고서에 명시한다.
- **HOLD** — 실제 DB 추가 변경, git 조작, 배포, Whitelist 확대처럼 별도 승인이
  필요한 항목. 해당 항목만 보류하고 나머지 안전한 작업(분석/구현/임시 DB 테스트/
  문서 작성)은 계속한다.
- **STOP** — 저장소 미연결, 금융 데이터 손상 가능성, 비밀정보 노출 가능성처럼
  즉시 전체 작업을 멈춰야 하는 상황. 이 등급에서만 전체를 중단하고 원인·영향·
  복구 가능성을 보고한다.

## 알림 발생 시점

작업 시작, 상태 복원 완료, 구현 전, 파일 변경 직후, 테스트 실행 전후, Migration
작성 후, DB 관련 명령 실행 전, Whitelist 위반 가능성 발견 시, 오류/예외/경고 발견
시, Phase 완료 시, 작업 종료 전. 동일한 내용은 반복 알리지 않고 상태·위험 등급이
바뀔 때만 새 알림을 낸다.

## 원칙

- INFO/NOTICE/WARNING에서는 사용자에게 계속 진행할지 묻지 않는다.
- HOLD에서는 승인 대상 항목만 언급하고 그 외 작업은 멈추지 않는다.
- STOP에서만 전체를 멈춘다.
- 테스트하지 않은 것을 통과로, 적용하지 않은 Migration을 완료로 기록하지 않는다.
