## 1. 시험상품 선정 기준(확정 아님 — 기준만)

시험상품 자체는 이 문서에서 확정하지 않는다. 다음 기준으로 사용자와
함께 최종 결정한다:

- **옵션이 단순함**: 색상/사이즈 등 선택지가 1~2개 이하 — 옵션 매핑
  오류 가능성을 낮춘다.
- **파손·변질 위험이 낮음**: 액체·유리·냉장 등 배송 중 파손·변질
  가능성이 있는 품목은 1순위에서 제외한다(반품 발생 시 원인 규명이
  어려워짐).
- **배송비가 명확함**: 온채널 상품상세에서 배송비가 고정값으로
  확인되고, "배송비 사전 확인 불가"(이전 라운드에서 이미 발견한
  구조적 제약, `docs/audits/...` 참고) 케이스에 해당하지 않는 상품.
- **반품 비용이 명확함**: 반품 시 왕복 배송비·회수 조건이 온채널
  상품상세 또는 공식 정책에서 확인 가능한 상품.
- **금액이 작음**: 시험 성격상 실제 손실 가능 금액을 최소화한다.

**참고(확정 아님, 2026-09-19 정정)**: 이번 대화 이전에 실행 주체
Codex가 실제로 `page=1, page_size=100, status=1`로 조회한 결과
`total_cnt=1, last_page=1`, 상품 CH1147184 "레이펄스 워터리스 샴푸/
바디워시" 1건이 응답됐다(감사 문서 30절 — 이전에 "page_size=1이라
1건만 나왔다"고 적었던 것은 실제 호출값을 확인하지 않은 채 코드
기본값으로 추측한 오류였고, 지금 정정한다). `page_size=100`이
`total_cnt=1`보다 훨씬 크므로 이 1건은 페이지 크기의 한계가 아니라
**"이 연결 계정의 status=1(정상판매) 상품이 정확히 1개"**라는
서버 자신의 보고다.

이 상품은 **액체(샴푸/바디워시)**이므로 위 "파손·변질 위험이 낮음"
기준에서 다른 후보와 비교가 필요하다 — 포장 방식(펌프형 용기, 밀봉
여부)에 따라 배송 중 누출 위험이 달라질 수 있으므로, 이 상품을 최종
후보로 쓸지는 사용자 확인 후 결정한다. 다만 "정상판매 상품이 1개"가
곧 "온채널 전체 상품이 1개"라는 뜻은 아니다 — `status` 파라미터는
1(정상판매)~5(품절) 중 하나만 거르는 필터이며, 단종·판매중단·
일시품절·품절 상태의 상품 유무는 이번 조회로 알 수 없다.

## 2. 온채널 상품목록 실제 확인이 필요하면(별도 승인 대상)

정상판매(status=1) 외 다른 상태의 상품이 있는지 보려면 `status`
파라미터를 생략하거나 2~5 값으로 각각 다시 조회해야 한다 — 이는 이번
문서 작성 시점까지 실행하지 않은 **추가 실 API 호출**이다(`page_size`
는 이미 최대값 100으로 조회됐으므로 더 늘릴 필요는 없다). 필요하면
목적("정상판매 외 상태 상품 존재 여부 확인")·경로(동일
`GET seller/product`)·최대 횟수(생략 조회 1회 우선 시도, 안 되면
상태값별 최대 4회 추가)·재시도 없음을 명시해 별도로 승인을 요청한다.

뿐, 정상판매 후보 발굴의 우선 작업이 아니다 — 지시문에서 명시적으로

## 2-2. 시험 구매 정책 확인 (7단계 — 시험 거래 정책 확인)

**확인한 공식 문서**: 쿠팡 「마켓플레이스 금지 행위 가이드라인(판매자 대상)」(2025-11-28,
`https://www.coupang.com/np/safety/news/detail?id=1007451`), 「쿠팡 판매자 관리 정책」
(`https://marketplace.coupang.com/blogs/blog-news8`, 2025-08-02), 쿠팡 마켓플레이스 자주 묻는
질문(`https://marketplace.coupang.com/faq`), 공개 검색. 온채널은 운영정책
(`https://onchannelnotice.oopy.io/1818e48b-f7dd-442b-af40-b094010ddce8`).

**결과: 쿠팡 공식 문서에서 "시험 주문 방법"이나 "판매자 본인 구매의 허용 조건"을 찾지 못했다.**
가이드라인은 판매량·배송 절차·WING 기능의 인위적 조작, 리뷰·평점 조작, 경쟁자 재고를 소진시킨
뒤 반품하는 행위를 금지하고, 명시되지 않은 행위라도 마켓플레이스 건전성을 해치면 허용하지
않는다고 적는다. "금지 문구가 없다"는 "허용된다"가 아니며, 사용자의 위험 수용으로 정책 미확인을
대신하지 않는다. 따라서 **정책 확인 전까지 실제 시험 주문(실제 주문 생성 단계)은 보류**하되,
상품 정보 정리·등록 초안·매핑 준비는 계속한다. 허위 주문·리뷰·평점·허위 반품 사유는 쓰지
않는다.

**공식 문의 경로**: 가이드라인 문서가 스스로 "이 가이드라인에 대한 문의는 쿠팡 판매자센터에
문의"하라고 안내한다(WING 판매자센터 문의). 이 세션에는 WING 로그인 권한이 없어 **문의를
발송하지 않았다** — 발송 승인(또는 사용자 직접 발송)을 요청한다. 문의 초안:

> 안녕하세요. 위탁(도매) 방식으로 상품을 판매하려는 판매자입니다. 신규 등록한 상품이 실제로
> 정상 주문·배송·반품 절차를 거치는지 검증하기 위해, 판매자 본인이 해당 상품을 쿠팡에서 1건
> 주문하고 정상 수령 후 필요 시 정책에 맞게 반품하려 합니다. 판매량·리뷰·평점 조작이나 노출
> 목적이 아니며, 리뷰·평점은 작성하지 않고 실제 배송지와 실제 결제를 사용합니다.
> (1) 이런 판매자 본인 시험 주문이 정책상 허용되는지, (2) 허용된다면 지켜야 할 조건(수량·횟수·
> 계정·결제수단·반품 사유 등)이 있는지, (3) 허용되지 않는다면 신규 상품의 주문·배송 흐름을
> 검증하는 쿠팡의 공식 방법(예: 테스트 주문 기능)이 있는지 안내를 부탁드립니다.

## 2-5. 온채널 발주 가능 상태 (판매신청은 별도 시험 항목이 아니라 발주의 준비 절차)

온채널 공식 답변(2026-09-10)에 따라 **발주 전 판매신청이 필수**이고, 코드도 이를
반영한다(`submit_order()`가 판매신청 접수 확인 전에는 발주를 막고
`ensure_sales_application_submitted()`를 호출). 세 상품 모두 운영채널분류가 "가격자율"이라
공개 화면상 일반 판매자가 신청 가능하지만, 이미 신청·접수된 상태인지는 확인하지 못했다.
따라서 7단계의 "온채널 발주 가능 상태 확인"에서: (1) 선택 상품의 판매신청 접수 여부를 먼저
확인하고, (2) 미접수면 **사용자 승인 후에만** 신청을 준비 절차로 수행한다. 승인 없이 신청하지도,
신청 필요 여부를 생략하지도 않는다(판매신청은 별도 "시험 항목"으로 추가하지 않는다).
