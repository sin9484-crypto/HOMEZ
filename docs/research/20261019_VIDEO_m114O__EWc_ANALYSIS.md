## 4. HOMEZ 관점의 위험·주의 (영상 기능을 그대로 따르지 않는 이유)

1. **권리:** 영상은 공급처 사진을 "중국 사진이고 저작권 문제 없다"고 하지만 근거를 보여 주지 않는다. HOMEZ는 RIGHTS_DENIED를 항상 막고, 확인 안 된 사진은 경고 확인 기록이 있을 때만 쓴다(R1).
2. **표시·광고:** AI가 옷의 색·모양·로고를 바꾸면 실제 상품과 다른 상품이 된다. 결과는 "참고 사진과 같은 상품인지" 사람이 검수해야 한다(`PRODUCT_MATCHES_REFERENCE`).
3. **대표 이미지:** 같은 날 앞서 "대표는 흰 배경만"으로 정했으나, 사용자가 "대표도 모든 배경·포즈 허용"으로 바꿨다(2026-10-19). R1은 대표 용도를 허용하되 **반려 위험 경고·대표 규격 검수 항목·사용자 최종 확인 필요 표시**를 자동으로 붙인다. 쿠팡 대표 이미지 규격(흰 배경 권장)과 AI 생성 이미지 정책은 🔴 미확인이라 반려될 수 있다.
4. **AI 생성 표기:** 생성된 이미지에는 "AI 생성 이미지" 표기를 붙인다는 내부 요구를 걸었다. 쿠팡이 AI 생성 이미지에 어떤 표기·제한을 요구하는지는 🔴 미확인이다(I0 정책 조사 필요).
5. **실제 인물 닮음:** 생성 모델이 실제 인물을 닮은 얼굴을 만들 수 있다. 얼굴·인물 식별 정보 검수(`NO_THIRD_PARTY_MARKS`)를 요구하되, 자동 검사 수단은 아직 없다.
6. **워터마크:** 사용자 지시로 생성 이미지에 워터마크·글자·로고를 넣지 않는다. 참고 사진에 워터마크가 있으면 결과에 따라 나올 수 있어 검수 항목(`NO_WATERMARK`)으로 요구한다. "AI 생성" 표기는 이미지 밖에만 둔다.
7. **실제 생성 API:** 이번 단계에서 연결하지 않았다. 연결하려면 가드 허용 호스트, 비용 승인, 정책 조사가 먼저다.
