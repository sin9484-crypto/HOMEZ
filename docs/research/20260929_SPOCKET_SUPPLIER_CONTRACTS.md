# Spocket 공급처별 계약 후속 조사

확인일: 2026-09-29. 공개 공식 자료 조사만 수행. 코드·업무 DB·자격증명·주문·결제 접근 및 변경 없음.

## 공식 확인

Spocket은 공급처별 반품 정책을 상품 페이지에서 확인하도록 안내하며, 환불 불가 정책을 가진 공급처도 있다고 명시한다. 파손·오배송은 수령 후 15일 이내 사진 증빙과 승인 절차가 필요하다. 주소 오류로 인한 재배송 비용은 판매자 부담이다. 배송완료 표시 후 미수령 주장은 운송사에 신고하도록 안내한다. 일반 반품은 지원팀 연락·공급처 승인·반송 추적번호 제공 등의 절차를 거친다. 따라서 모든 공급처에 동일한 반품·자동환불 계약을 적용하면 안 된다.

근거: [공식 반품·교환·환불 안내](https://help.spocket.co/en/articles/4193234-how-do-returns-exchanges-and-refunds-for-orders-work-on-spocket).

공식 연동 소개 페이지는 존재하지만, 이번 공개 검색에서 HOMEZ 같은 독립 앱에 부여되는 주문·취소·환불 API 권한과 계약은 확보하지 못했다. 기존 쇼핑몰 앱 연동 지원을 공개 API 제공의 증거로 취급하지 않는다.

근거: [공식 연동 소개](https://www.spocket.co/integrations).

## 미확인과 우선순위

한국 사업자의 판매자 가입 자격, 한국 직배송 가능한 실제 SKU·창고, MOQ, 목적지별 비용·배송기간, 결제수단·통화, 통관 책임, 한국어 지원 및 API 승인은 미확인이다. 공급자로 입점하는 조건과 HOMEZ가 매입하는 소매판매자 조건을 혼동하지 않는다.

해외 직배송 후보로 유지하되 국내 위탁·직접 사입과 구분한다. 개별 공급처의 한국 배송과 반품 계약, 독립 API 권한 확인이 Adapter 착수보다 먼저다. 현재 국내 공급처 우선순위를 바꿀 근거는 없다.

## 가상 운영 시나리오

- 정상 주문: 공급처·SKU·한국 목적지·옵션·총비용·반품 정책을 함께 확인한다.
- 가격변경: 승인 금액과 배송비 포함 최신 견적을 대조하고 인상 시 재승인한다.
- 품절: 자동 대체 없이 해당 주문 실행을 보류한다.
- 결제 결과불명: 중복 결제하지 않고 공식 주문·결제 대조 경로를 확인한다. API 계약이 없으면 자동화 개방을 보류한다.
- 배송: 운송사 배송완료와 실제 고객 수령 주장을 구분한다. 분쟁 증빙·신고 기한을 기록한다.
- 반품: 공급처별 승인·주소·기한·추적번호를 확인하고 고객 환불과 공급처 환급을 별도 상태로 관리한다.

위 항목은 설계 제안이며 실제 플랫폼 실행 검증이 아니다. 전체 공급처 조사 완료가 아니며 현재 사용자 결정이나 운영 변경은 필요하지 않다.
