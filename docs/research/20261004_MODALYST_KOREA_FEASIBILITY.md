# Modalyst 한국향 활용 조건 조사

확인일: 2026-10-04. 공개 공식 자료만 조사했다. 코드·업무 DB·자격증명·주문·결제는 다루지 않았다. 전체 공급처 조사 완료나 도입 승인이 아니다.

## 공식 근거와 판정

- 국제배송은 다수 공급처가 지원하지만 공급처가 지역별 배송을 해제할 수 있다. 상품별 전체 목적지·배송비 목록을 확인해야 한다. 한국향 전 상품 지원으로 확대하지 않는다. [공식 국제배송 안내](https://support.modalyst.co/en/articles/1013678-do-your-suppliers-ship-internationally)
- 반품은 공급처별 정책을 따르며, 인정된 반품에서는 공급처에 지불한 상품대금을 환급한다. Modalyst 거래 수수료는 반환하지 않는다고 명시한다. 상품대금 환급과 총비용 회복은 다르다. [공식 환급 안내](https://support.modalyst.co/en/articles/1013663-how-much-do-i-get-refunded-if-my-customer-decides-to-return-a-product)
- 플랫폼은 통관·관세를 처리하지 않으며 최종 소비자 부담이라고 안내한다. 이것은 플랫폼 설명이며 한국 수입주체·통관·세금의 법적 판정을 대체하지 않는다. 문서의 다른 국가 세율·면세 예시는 한국에 적용하지 않았다. [공식 통관 안내](https://support.modalyst.co/en/articles/1013670-who-covers-customs-and-taxes-through-modalyst)
- Wix의 공식 연동 안내는 일반적인 14일 반품 정책을 설명한다. Modalyst 자체 안내의 공급처별 조건과 함께 확인해야 하며 모든 상품의 무조건 환불 보장으로 처리하지 않는다. [Wix 공식 설정 안내](https://support.wix.com/en/article/wix-stores-setting-up-modalyst-dropshipping-via-the-wix-dashboard)

## 미확인 범위

한국 사업자 가입 자격, 실제 한국 배송 SKU·기간·요금, MOQ, 결제수단·통화, 한국어 운영 지원, 독립 HOMEZ 앱의 API 승인·범위·취소·환불·결과불명 조회 계약은 이번 조사에서 미확인이다. Wix 앱 지원을 독립 API 개방의 증거로 사용하지 않는다. 공개 검색에서 문서를 못 찾은 것과 API가 존재하지 않는다는 판정도 구분한다.

## 비교와 우선순위

해외 직배송 후보로 유지한다. 국내 위탁배송이나 국내 재고 사입과 같은 계약으로 취급하지 않는다. Syncee·Spocket처럼 플랫폼명보다 실제 공급처·상품·목적지 단위 평가가 우선이며, 환급 제외 수수료를 비용 모델에 반영해야 한다. 한국향 계약과 독립 연동 권한 확인 전 Adapter 착수 우선순위를 높이지 않는다.

## 가상 운영 시나리오

실행 검증이 아닌 HOMEZ 설계 제안이다.

| 상황 | 처리 제안 |
| --- | --- |
| 정상 주문 | 공급처·옵션·한국 목적지·통관 책임·총비용·반품 조건 확인 후 승인 |
| 가격변경 | 상품가·배송비·거래 수수료를 함께 비교하고 총액 인상 시 재승인 |
| 품절 | 대체 상품 자동 주문 금지, 공급 가능 여부 확인까지 보류 |
| 결제 결과불명 | 자동 재결제 금지, 공식 주문·결제 대조 경로가 없으면 사람에게 이관 |
| 배송 | 공급처별 목적지 제한과 추적 상태 관리, 통관 지연을 배송완료로 처리하지 않음 |
| 반품 | 고객 환불과 공급처 회수를 분리하고 반환되지 않는 거래 수수료를 손실 추정에 반영 |

현재 사용자 결정이나 운영 변경은 필요하지 않다. 후속 조사는 한국향 개별 공급처와 API 계약 확보 가능성에 집중한다.
