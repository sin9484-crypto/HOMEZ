# 공급처 정기 조사: Zendrop·Syncee

확인일: 2026-09-24. 공개 공식 문서 조사만 수행. 가입·인증 API·코드·DB·주문·결제 변경 없음. 전체 공급처 조사 완료나 도입 확정이 아니다.

## 확인 결과

| 후보 | 공식 확인 | 미확인·제약 | HOMEZ 우선순위 판단 |
| --- | --- | --- | --- |
| Zendrop | 배송 가능 국가 목록에 한국 포함. 국가 목록 등재가 모든 상품 배송을 보장하지 않는다고 명시 | 상품·주소별 배송, 한국 사업자 계약과 결제, 독립 앱 API 권한·범위, MOQ·반품·한국어 지원은 이번 조사에서 미확인 | 해외 직배송 후보 유지. 국가 지원만으로 Adapter 착수하지 않음 |
| Syncee | 공급처가 고객에게 직접 배송하며 배송 지역·창고는 공급처별로 확인. 반품·환불도 공급처 조건에 따라 처리 | 플랫폼 전체를 동일 배송·반품 계약으로 취급 불가. 한국향 실제 공급처·계약·API·결제·MOQ 미확인 | 플랫폼보다 실제 공급처 단위 평가가 먼저 |

국내 위탁·사입과 별개인 해외 직배송 후보 조사다. 통관·품목 인증·자료 이용권리 충족 여부는 이 문서로 판정하지 않는다. 기존 국내 우선 준비 순서를 바꿀 근거는 확보되지 않았다.

## 가상 운영 시나리오 (제안, 플랫폼 기능 검증 아님)

- 정상 주문: 상품·공급처·한국 목적지·배송비·옵션·권리 확인 후 승인된 실행만 진행. 배송 국가 지원은 상품별 견적 확인을 대체하지 않음.
- 가격변경: 승인 당시 총비용과 재조회 값을 비교하고 인상 시 발주 중지·알림·재승인.
- 품절: 대체 상품으로 자동 치환하지 않고 해당 품목 실행 보류.
- 결제 결과불명: 재결제 금지, 공식 주문·결제 조회 방법으로 대조. 해당 방법이 미확인이면 자동화 개방 보류.
- 배송: 창고·운송방법·추적 결과를 주문별로 보존. 플랫폼 평균 배송기간을 도착 보장일로 표시하지 않음.
- 반품: 주문 당시 공급처 정책과 비용·주소·기한을 보존하고 사용자 승인 후 처리. Syncee 전체 공통 환불 조건을 가정하지 않음.
