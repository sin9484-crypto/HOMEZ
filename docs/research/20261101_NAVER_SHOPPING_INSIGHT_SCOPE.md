# 네이버 쇼핑인사이트 공식 API 검토 (2026-11-01, 사용자 결정 D3 "공식 API 검토 먼저")

코드 변경 없음. 트렌드 키워드를 어디서 가져올지 정하기 위한 조사다.

## 결론

**쇼핑인사이트 API는 "유행 키워드를 찾아 주는" 자료원이 아니다.** 확인한 공식 문서의 엔드포인트 목록에 분야별 인기 검색어 순위(TOP 목록)를 주는 것이 없다. 사람이나 규칙이 정한 분야·키워드의 상대 추이만 돌려준다.

그래서 이 API만으로는 "키워드를 스스로 찾지 못한다"는 트렌드 탐색의 한계가 풀리지 않는다. 쓸 수 있는 곳은 키워드가 정해진 뒤의 **비교·점수 보강**이다.

## 확인한 사실

출처: 네이버 클라우드 API HUB 공식 문서(아래 링크). 해당 가이드 페이지에는 `stale: true`, 갱신일 2026-09-17로 표시돼 있다.

| 항목 | 내용 |
|---|---|
| 엔드포인트 | 분야별 트렌드 `POST /shopping/v1/categories`, 키워드별 트렌드 `POST /shopping/v1/category/keywords`, 그 외 분야·키워드의 기기별·성별·연령별(목록만 확인, 상세 미확인) |
| 인기 검색어 TOP 목록 | **문서에 없음** |
| 응답 값 | 상대 지수 `ratio`(구간에서 가장 큰 값을 100으로 둔 값). 검색 클릭 추이이며 절대 클릭 수·검색량은 주지 않는다 |
| 조회 기간 | 2017-08-01부터, 단위는 일·주·월 |
| 키워드별 필수 입력 | 분야 코드 1개 + 키워드 그룹 최대 5개(그룹당 검색어 1개) |
| 분야별 필수 입력 | 분야 최대 3개 |
| 분야 코드 | 코드 목록은 문서에 없음. "네이버쇼핑에서 카테고리를 고르면 URL의 `cat_id`"로 확인하라고 안내 |
| 호출 한도 | 쇼핑인사이트 월 50,000건(검색어 트렌드와 별도), 키당 초당 50회. 한도에 닿으면 자동 차단 |
| 비용 | "한시적 무료", 유료 전환 시 사전 공지 예정. 단가는 확인하지 못함 |
| 인증 | 검색어 트렌드와 같은 API HUB 헤더 두 개. Application 등록 때 **쇼핑인사이트를 API로 선택해야 함**. 한 Application에서 둘 다 선택 가능 |

## 확인하지 못한 것

- 네이버 개발자센터 원문(`developers.naver.com`)은 접근이 막혀 읽지 못했다. 다른 API 체계의 한도·조건은 미확인이다.
- 기기·성별·연령별 엔드포인트의 파라미터 상세, 요금 단가.
- 지금 저장된 HOMEZ의 네이버 키에 쇼핑인사이트가 선택돼 있는지(🔴 실제 호출·콘솔 확인 전이라 모른다).
- 문서 안의 불일치: 429를 한쪽은 월 한도, 공통 응답 표는 "하루 허용량 초과"로 적었다. 일일 한도 수치는 찾지 못했다.

## 현재 코드와 어긋나는 점 (자동으로 고치지 않음)

`app/domains/trend_discovery/adapter.py`의 `MONTHLY_CALL_LIMIT`와 상태 문서는 검색어 트렌드 무료 한도를 **월 30,000회**로 적었고, 이번에 읽은 문서는 **월 50,000건**이다. 코드의 낮은 값이 더 안전한 쪽이라 바꾸지 않았다. 네이버 콘솔에서 실제 값을 확인한 뒤 정한다.

## 선택지

| 방안 | 할 수 있는 일 | 못 하는 일 | 필요한 것 |
|---|---|---|---|
| A. 사람 입력 목록 + 지금의 검색어 트렌드 | 등록한 키워드의 관심도 추이를 매일 조회 | 키워드 발견 | 화면 1개, 추가 키 없음 |
| B. A + 쇼핑인사이트 | A에 더해 **쇼핑 분야 안의** 클릭 추이로 비교 | 키워드 발견 | 분야 코드 관리, Application에 API 추가 |
| C. 공급처 카테고리를 쇼핑인사이트 분야에 연결 | 어느 분야가 뜨는지 보기 | 개별 상품 키워드 | 카테고리↔분야 코드 대응표를 사람이 만들어야 함 |

**추천: A부터.** 키워드 발견은 어느 쪽도 풀지 못하므로 키워드는 사람이 정해야 한다. A는 추가 키 없이 바로 쓸 수 있다. B는 A에서 키워드 수가 늘어 쇼핑 맥락의 비교가 필요해질 때 붙이면 된다.

**결정(사용자 확정 2026-11-01): A. 사람 입력 목록 + 지금의 검색어 트렌드.** 구현은 `app/domains/trend_discovery/keyword_watch_service.py`. 쇼핑인사이트는 연동하지 않았다.
