# EPROLO 한국향 배송 조건 후속 조사

확인일: 2026-09-28. 공개 공식 자료 조사만 수행했다. 코드·DB·자격증명·주문·결제는 다루지 않았다.

## 확인과 한계

- 홈페이지는 국제 특송과 30일 배송 보장을 소개한다. 이를 한국향 모든 상품의 보장으로 해석할 수는 없다. [공식 홈페이지](https://eprolo.com/)
- 별도 배송 안내는 지역별 30일 또는 60일, 성수기 40일 조건과 주소 오류·미수령·불가항력 등의 예외를 명시한다. 배송비는 목적지와 운송방법에 따라 달라진다. 한국의 적용 구간은 이 안내만으로 명확하지 않다. [공식 배송 안내](https://eprolo.com/shipping-methods)
- 배송 안내에는 환불 지연 산정의 출고일과 예상 배송기간의 송장 생성일이 구분돼 있다. 주문일 하나로 모든 기한을 계산하면 안 된다. 같은 문서는 2020년 게시로 표시돼 있어 현재 한국향 계약에 대한 별도 확인이 필요하다. 위 배송 안내를 근거로 한다.

## HOMEZ 적용 판단

해외 직배송 후보 지위를 유지하되 한국향 고정 배송일·자동 환불 보장을 설정하지 않는다. 국내 위탁·사입의 배송 정책을 재사용하지 않는다. 한국 사업자 가입, SKU별 한국 배송, MOQ, 결제 통화·수단, 통관 책임, 한국어 지원 및 비공개 API 계약은 여전히 미확인이다.

## 가상 시나리오 보완

- 정상 주문: 상품·목적지별 운송방법과 견적, 적용 정책을 확인한 뒤 승인한다.
- 가격변경: 상품가와 배송비를 함께 재대조한다. 총액 인상은 재승인 대상으로 둔다.
- 품절: 임의 대체하지 않고 실행을 보류한다.
- 결제 결과불명: 재결제하지 않고 공식 주문·결제 대조 방법을 확인한다. API 지원 여부는 미확인이다.
- 배송: 주문일·출고일·송장 생성일을 구분하고 확정된 정책의 기준일만 사용한다.
- 반품·환불: 홈페이지의 30일 문구만으로 자동 환급을 예상하지 않는다. 한국향 적용 조건과 예외 확인 전에는 수동 검토한다.

실제 시뮬레이션 실행 결과가 아닌 설계 제안이다. 도입 우선순위 변경이나 현재 사용자 결정은 필요하지 않으며, 전체 공급처 조사는 계속된다.
