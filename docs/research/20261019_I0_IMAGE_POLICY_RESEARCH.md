# I0 조사: 쿠팡 대표 이미지 규격과 AI 생성 이미지 정책 (2026-10-19)

- 목적: 사용자가 "대표 사진도 AI로 만들 수 있게" 허용했으므로(2026-10-19), 쿠팡이 대표 이미지에 AI 생성 사진을 받아 주는지 확인한다.
- 방법: 공개 웹 검색 3회(한국어 2, 영어 1). **읽기 전용** — 쿠팡 판매자센터(WING) 로그인·쿠팡 API 호출 없음.
- 구분: 🟢 공식 문서 직접 확인 / 🟡 2차 출처(블로그·셀러 커뮤니티·타사 소개)에서 본 내용 / 🔴 확인하지 못함

## 결론

**쿠팡의 공식 문서(대표 이미지 규격·AI 생성 이미지 정책)는 이번 검색에서 찾지 못했다.** 따라서 "대표에 AI 사진을 써도 되는가"는 🔴 미확인이다. 아래 🟡 내용은 판매자 블로그가 정리한 것이라 쿠팡의 규정으로 취급하지 않는다.

## 1. 대표 이미지 규격

| 항목 | 내용 | 수준 |
|---|---|---|
| 흰 배경 | 깨끗한 흰 배경 권장 | 🟡 판매자 블로그 다수 |
| 상품 점유 | 상품이 캔버스의 85% 초과(아마존 규칙과 같은 수치라 혼선 가능) | 🟡 |
| 글자·그래픽 | 이미지 위 텍스트·그래픽 금지 | 🟡 |
| 실물과 동일 | 고객이 받는 모습과 같게, 사은품 노출 금지 | 🟡 |
| 위반 시 | 광고 노출 제한 | 🟡 한 블로그의 주장 |
| 예외 카테고리 | 의류·신선식품·포장식품 등에 예외가 있다는 언급이 있으나 세부는 확인 못 함 | 🔴 |
| 모델 착용·연출 대표 | 카테고리별로 허용 여부가 다르다는 설명(허용 카테고리 목록은 원문 첨부) | 🟡 / 목록 🔴 |
| 이미지 자동 수정 동의 | 동의 시 이미지가 흰 배경으로 바뀔 수 있다는 주장 — 실제 동작 | 🔴 WING에서 직접 확인 필요 |

저장소의 기존 조사(`docs/HOMEZ_V7_UNIVERSAL_LISTING_AND_IMAGE_RIGHTS_RESEARCH.md`)도 "대표 이미지 제품 점유율 95%"와 "WING이 대표 이미지 로고 노출을 허용하는지"를 `UNCONFIRMED`로 남겨 두었다. 이번 조사는 그 상태를 바꾸지 못했다.

## 2. AI 생성 이미지 정책

| 항목 | 내용 | 수준 |
|---|---|---|
| 쿠팡의 AI 생성 이미지 허용·제한·표기 의무 | 검색에서 쿠팡 공식 문서가 나오지 않았다 | 🔴 |
| 아마존(비교용, 쿠팡 아님) | 실제 사람처럼 보이는 AI 생성 인물 이미지에는 메타데이터 표기를 요구하기 시작했다(뉴욕주 법 계기). 메인 이미지는 글자·로고·워터마크·테두리 금지 | 🟡 뉴스 보도 |
| 국내 법령(표시·광고, 인공지능 관련 표시 의무) | 이번 검색으로 조항을 확인하지 못했다. 법무 확인 필요 | 🔴 |
| 일반 원칙 | 실제 상품과 다르게 보이는 이미지는 정책 위반 이전에 표시·광고 분쟁 위험이 있다 | 🟡 |
| 초상권 | 실존 인물과 닮은 AI 모델은 초상권 문제가 될 수 있어 합성 모델이 안전하다는 안내 | 🟡 |

## 3. 이 조사가 HOMEZ에 주는 영향

1. **대표 AI 사진은 반려·노출 제한 위험이 실제로 있다.** R1이 대표 요청에 붙인 반려 위험 경고와 사용자 최종 확인 표시는 이 미확인 상태에 맞는 장치다. 경고 문구("정책은 아직 확인하지 못했습니다")는 이번 조사 후에도 사실이다.
2. **워터마크·글자 금지**(사용자 지시)는 대표 이미지 글자 금지 원칙(🟡)과 방향이 같다. 이미지 안에 "AI 생성" 표기를 굽지 않고 이미지 밖에 두는 설계도 맞다.
3. **가장 안전한 대표 구성**은 참고 사진을 바탕으로 한 흰 배경·상품 중심 컷이다. 사용자가 모든 배경·포즈를 허용했으므로 코드는 막지 않지만, R3 화면에서는 대표 요청의 **기본 선택을 흰 배경(단색 스튜디오)** 으로 두는 것을 권고한다(선택은 사용자가 바꿀 수 있다).
4. 공식 확인 경로 두 가지(사용자 몫): ① WING 판매자센터의 상품 이미지 가이드·공지(로그인 필요) 직접 읽기, ② 쿠팡 판매자 지원에 AI 생성·AI 편집 대표 이미지 허용 여부와 표기 필요 여부를 서면 문의. 두 방법 모두 제가 대신 하지 않았다(로그인·문의 발송).
