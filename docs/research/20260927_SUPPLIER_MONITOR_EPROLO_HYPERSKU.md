# 공급처 정기 조사: EPROLO·HyperSKU

확인일: 2026-09-27. 공식 공개 자료만 조사했다. 계정 가입, 인증 API 호출, 코드·업무 DB·자격증명 접근, 주문·결제는 수행하지 않았다. 전체 후보 조사 완료 또는 도입 승인이 아니다.

## 확인 결과

### EPROLO: API 제공과 연동 가능 판정을 구분

공식 API 안내는 무료 연동을 소개하지만, 가입 후 담당 지원자에게 요청하여 메시지함으로 문서를 받는 절차다. 공개 안내만으로 HOMEZ에 필요한 주문·취소·환불·멱등성 계약이 확보됐다고 볼 수 없다. 다음 단계는 문서와 이용 권한 확인이며, Adapter 구현 우선순위를 높일 근거는 아직 부족하다.

근거: [EPROLO API 안내](https://eprolo.com/eprolo-api/).

### HyperSKU: 품목·배송방법별 손실 위험

공식 사후처리 정책은 보충제에 환불·재배송·교환을 제공하지 않으며, Special Shipping에도 지연·배송 실패 시 환불·재배송을 제공하지 않는다고 명시한다. 따라서 일반 상품의 보상 조건을 이 조합에 재사용하면 안 된다.

일반 파손·불량 신청은 수령 후 7일 이내 증빙이 필요하다. 배송 실패 후 재배송은 7일 이내 요청과 건당 USD 15 비용 조건이 있으며, 일부 지연 보상은 배송방법·예상 배송일을 기준으로 별도 적용된다. 승인된 환불도 결제처 수수료는 제외된다. 신청은 담당자를 거친다.

근거: [HyperSKU 공식 사후처리 정책](https://support.hypersku.com/en/articles/6765770-hypersku-aftersales-policy-can-i-refund-reship-or-return-hypersku-orders).

## 미확인 항목과 적용 우선순위

두 후보 모두 이번 조사만으로 한국 사업자 가입 자격, 한국 목적지별 실제 배송 가능 상품·기간, MOQ, 결제수단·통화, 통관 책임, 한국어 지원, API 승인 범위와 주문 결과불명 대조 방법을 확정하지 않는다. USD로 표시된 재배송 비용은 전체 결제 통화의 증거가 아니다.

해외 직배송 후보로 평가하되 국내 위탁·사입 또는 해외 일괄 사입과 같은 계약으로 취급하지 않는다. EPROLO는 API 계약 확보가 선행이고, HyperSKU는 일반 상품·보상 가능한 운송방법부터 검토한다. 보충제·Special Shipping 조합은 HOMEZ 자동화 우선 후보에서 보류하는 것을 제안한다. 공급처 보상 제외와 HOMEZ의 고객 대응 의무는 별개이며, 후자는 이 자료로 법적 판정하지 않는다.

## 가상 운영 시나리오

아래는 HOMEZ 설계 제안이며 실제 플랫폼 기능 시험 결과가 아니다.

| 상황 | 제안 처리와 후속 조건 |
| --- | --- |
| 정상 주문 | SKU·목적지·수량·총비용·운송방법·당시 보상 정책을 함께 확인. API 권한과 결과 조회 계약 없이는 자동 발주 개방 금지 |
| 가격변경 | 승인 금액과 새 견적을 대조하고 인상 시 재승인. 배송방법 변경에 따른 보상 조건 변화도 별도 확인 |
| 품절 | 임의 대체 금지. 공급 가능 여부와 납기를 확인할 때까지 해당 주문 실행 보류 |
| 결제 결과불명 | 자동 재결제 금지. 공급처 주문번호·결제 결과를 공식 경로로 대조할 수 없으면 사람에게 이관 |
| 배송 | 실제 운송방법과 예상일·수령일 기준으로 증빙 제출 기한 관리. 평균 배송기간을 보장으로 표시하지 않음 |
| 반품·환불 | 고객 환불과 공급처 회수 가능 금액을 분리. 보상 제외 상품·운송방법은 공급처 환급을 예상 수입으로 잡지 않음 |

## 다음 조사

실행이나 정책 변경은 하지 않았다. 후속 조사에서 EPROLO의 공개 배송 조건 및 HyperSKU 약관과 사후처리 문서의 적용 우선관계를 추가 대조한다. 계정 승인이 필요한 비공개 계약은 공개 조사로 확인한 것처럼 기록하지 않는다.
