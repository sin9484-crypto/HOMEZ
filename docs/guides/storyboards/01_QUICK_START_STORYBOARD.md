## 제작 시 준수 사항 (공통 영상 제작 규칙 반영)

- 작은 글씨(아이디/비밀번호 입력창, 배지 텍스트)는 반드시 확대(zoom-in)
  컷을 삽입한다.
- 배경 음악을 쓸 경우 내레이션보다 최소 -18dB 낮게 유지한다.
- 자막 표시 시간은 문장당 최소 1.5초 이상 확보한다.
- 실제 비밀번호 입력 장면은 절대 실제 값이 보이지 않게 마스킹 처리한다
  (이 가이드의 데모 계정도 화면 녹화 전 반드시 값 마스킹 확인).
- 알림 영역/작업 표시줄/주소창에 개인 폴더 경로 등 부가 정보가 노출되지
  않는지 최종 컷 전에 확인한다.
