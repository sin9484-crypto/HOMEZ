- 초대 코드·복구 코드는 어떤 프레임에서도 실제 값이 읽히지 않게
  모자이크한다.
- 사용자 관리 표의 이메일은 전부 가상 도메인(`homez-guide-demo.com`)
  이며, 실제 고객/직원 정보가 아님을 내레이션에서 한 번 언급한다.
