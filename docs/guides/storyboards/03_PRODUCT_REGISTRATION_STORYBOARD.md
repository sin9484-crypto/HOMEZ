# Storyboard — Guide 3: 상품 등록 전체 과정

- 형식: Desktop 1920x1080 MP4, ≥30fps (영상 미제작 — 도구 부재)
- 총 목표 길이: 10~15분

| # | 시간(초) | 화면/소스 | 동작 | 클릭 강조 | 자막 큐 |
|---|---|---|---|---|---|
| 1 | 0-15 | 타이틀 카드 + 플로우 다이어그램 | 전체 흐름(후보→승인→마법사 10단계→8단계 승인→9단계 실행) 소개 | 없음 | S1 |
| 2 | 15-60 | `04_candidates_with_virtual_item.png` | 상품 후보 표의 각 컬럼(트렌드/신제품/마진/자금/위험도/상태)을 순서대로 강조 | 컬럼별 하이라이트 | S2 |
| 3 | 60-90 | `03_listing_wizard.png` | 마법사 개요 화면, "새 마법사 시작" 버튼 강조 | 클릭 포인트: 새 마법사 시작 | S3 |
| 4 | 90-140 | `05_listing_wizard_start_click.png` | 1단계 화면 확대, 진행률 표시줄과 ProductCandidate ID 입력창 강조 | 필드 확대 | S4 |
| 5 | 140-230 | 텍스트 카드(코드 기준 표) | 2~10단계 이름을 순서대로 자막과 함께 나열(실제 화면 없음을 자막에 명시) | 없음 | S5 |
| 6 | 230-280 | `02_marketplace_listing_banner.png` | LIVE_E2E 경고 배너 확대 | 배너 확대 | S6 |
| 7 | 280-300 | 엔딩 카드 | "다음: 가이드 4. 모바일 사용법" | 없음 | S7 |

## 준수 사항

- 5번 장면은 실제 화면 캡처가 아니므로, 반드시 "실제 화면이 아니라
  코드 기준 설명입니다"라는 자막/워터마크를 넣는다.
- 상품 후보의 "(가상 데모 상품)" 표기가 잘리지 않도록 확대 컷에서
  전체 문자열이 보이게 한다.
