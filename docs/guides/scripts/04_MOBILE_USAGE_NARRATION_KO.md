# 내레이션 대본 — 가이드 4: 모바일 사용법 (한국어)

**S1 (0-10초)**
> HOMEZ V6.5 모바일 사용법입니다. HOMEZ는 별도 앱이 아니라 브라우저
> 반응형 화면으로 모바일을 지원합니다.

**S2 (10-30초)**
> 모바일에서도 로그인 화면은 같은 구조를 유지하며 폭만 좁아집니다.

**S3 (30-60초)**
> 로그인하면 화면이 좁아 좌측 메뉴가 기본적으로 숨겨지고, 대신 상단
> 왼쪽에 햄버거 아이콘이 나타납니다.

**S4 (60-90초)**
> 햄버거 아이콘을 누르면 데스크톱과 똑같은 메뉴가 화면 위로
> 슬라이드되어 나타납니다.

**S5 (90-140초)**
> 430, 390, 360 픽셀 너비에서 모두 확인했습니다. 카드가 세로로
> 쌓이는 구조를 그대로 유지하며 잘리는 부분이 없습니다.

**S6 (140-180초)**
> 매니저 권한으로 상품 후보 화면에 들어가면 데스크톱과 똑같이
> 접근이 차단됩니다. 화면 크기와 관계없이 서버가 권한을 동일하게
> 검사한다는 뜻입니다.

**S7 (180-200초)**
> 다음 영상은 문제 해결과 안전 사용입니다. 시청해 주셔서 감사합니다.
