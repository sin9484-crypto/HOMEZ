# 내레이션 대본 — 가이드 3: 상품 등록 전체 과정 (한국어)

**S1 (0-15초)**
> HOMEZ V6.5 상품 등록 전체 과정입니다. 상품 후보 승인부터 상품등록
> 통합 마법사의 10단계, 그리고 실제 등록이 실행되는 시점까지
> 안내합니다.

**S2 (15-60초)**
> 상품 후보 화면에는 트렌드 점수, 신제품 여부, 예상 마진, 필요 운영
> 자금, 위험도, 상태가 표로 나타납니다. 이 데모에서는 실제 데이터
> 대신 가상 상품 하나를 직접 넣어 화면 구조를 보여드립니다.

**S3 (60-90초)**
> 상품등록 통합 마법사로 들어가면 아직 생성된 위저드가 없다는 안내와
> 새 마법사 시작 버튼이 보입니다.

**S4 (90-140초)**
> 새 마법사를 시작하면 1단계 · 상품 소스 화면이 나타납니다. 열 단계
> 중 1단계이며, 승인된 상품 후보의 ID를 입력합니다.

**S5 (140-230초)**
> 이 영상에서는 실제 등록을 유발하지 않기 위해 2단계부터 10단계까지는
> 실제로 진행하지 않았습니다. 코드에 정의된 실제 단계 이름만
> 알려드립니다: 상품 초안, 이미지, 판매채널, 판매 방식, 가격·마진,
> 사전검사, 승인, 실행 선택, 결과. 8단계 승인을 통과해야만 9단계에서
> 실제 등록이 실행됩니다.

**S6 (230-280초)**
> 채널별 판매 방식 화면에는 이런 경고 배너가 있습니다. 이 경로로
> 실제 쿠팡이나 네이버에 데이터를 보내는 코드는 아직 없습니다.

**S7 (280-300초)**
> 다음 영상은 모바일 사용법입니다. 시청해 주셔서 감사합니다.
