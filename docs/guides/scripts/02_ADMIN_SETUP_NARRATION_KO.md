# 내레이션 대본 — 가이드 2: 관리자 초기 설정 (한국어)

**S1 (0-10초)**
> HOMEZ V6.5 관리자 초기 설정 가이드입니다. 회원가입부터 초대 코드,
> 사용자 관리, 판매채널 연동 화면 진입까지 안내합니다.

**S2 (10-40초)**
> 새 팀원은 로그인 화면의 회원가입을 통해 가입을 신청합니다. 이메일,
> 표시 이름, 비밀번호를 입력하고, 비밀번호는 10자 이상, 대소문자,
> 숫자, 특수문자 조건을 만족해야 합니다. 회사 초대 코드는 선택
> 사항이며, 없어도 신청은 가능하지만 관리자 승인 전까지는 이용할 수
> 없습니다.

**S3 (40-70초)**
> 관리자는 설정 화면의 가입 승인 대기 목록에서 신청을 확인하고
> 승인하거나 거절할 수 있습니다.

**S4 (70-110초)**
> 같은 화면에서 초대 코드를 발급할 수 있습니다. 부여할 최대 역할을
> 고르고 코드 생성 버튼을 누르면 코드가 발급됩니다. 이 코드는 매우
> 민감한 정보이므로 화면에서는 가려서 보여드립니다.

**S5 (110-160초)**
> 아래에는 회사 소속 사용자 전체 목록이 있습니다. 각 사용자의 역할을
> 바꾸거나 비활성화하거나 비밀번호 재설정을 시작할 수 있고, 아래
> 폼으로 새 사용자를 직접 추가할 수도 있습니다.

**S6 (160-200초)**
> 판매채널 연동 메뉴로 들어가면 쿠팡·네이버 연동 절차 안내가
> 나타납니다. 화면에 표시된 것처럼 이 절차는 참고용 예시이며, 실제
> 판매자센터 화면은 달라질 수 있습니다. 이 영상에서는 실제 계정
> 정보를 입력하지 않습니다.

**S7 (200-260초)**
> 설정 화면에는 언어 전환, 비밀번호 변경, 세션 관리, 복구 코드 생성
> 기능이 모두 모여 있습니다. 복구 코드는 생성 직후 한 번만 표시되므로
> 반드시 안전한 곳에 보관해야 합니다. 여기서도 실제 코드는 가려서
> 보여드립니다.

**S8 (260-280초)**
> 다음 영상에서는 상품 등록 전체 과정을 다룹니다. 시청해 주셔서
> 감사합니다.
