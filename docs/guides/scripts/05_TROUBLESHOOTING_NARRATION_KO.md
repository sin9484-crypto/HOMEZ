# 내레이션 대본 — 가이드 5: 문제 해결과 안전 사용 (한국어)

**S1 (0-10초)**
> HOMEZ V6.5 문제 해결과 안전 사용 가이드입니다. 자주 만나는 화면과
> 정확한 대응 방법을 안내합니다.

**S2 (10-50초)**
> 아이디나 비밀번호가 틀리면 이렇게 표시됩니다. 어떤 값이 틀렸는지는
> 알려주지 않는데, 이것은 보안을 위한 의도된 설계입니다.

**S3 (50-100초)**
> 상단 상태 배지가 관리자 계정에서는 전부 초록색이지만, 매니저
> 계정에서는 세 개가 빨간색으로 바뀝니다. 이것은 오류가 아니라 그
> 정보를 조회할 권한이 없다는 뜻입니다.

**S4 (100-140초)**
> 관리자 전용 화면에서 이런 메시지를 보면, 관리자 계정으로 다시
> 로그인하거나 관리자에게 권한을 요청하세요.

**S5 (140-200초)**
> 실제로 발생하는 주요 오류 코드입니다. 401은 로그인 오류, 403은
> 권한 부족, 423은 Migration 제한 모드, 429는 판매채널 API 호출
> 빈도 제한입니다.

**S6 (200-250초)**
> 안전 사용을 위한 네 가지 규칙입니다. 초대 코드와 복구 코드는 절대
> 캡처하지 마세요. Fake Provider 화면임을 항상 기억하세요. 준비 중
> 메뉴는 눌러도 안전합니다. Migration 승인은 반드시 관리자만
> 수행하세요.

**S7 (250-280초)**
> 지원팀에 문의할 때는 진단 내보내기 API를 활용하세요. 현재는 화면
> 버튼이 없어 관리자가 직접 호출해야 하지만, 그 결과를 첨부하면
> 문제 해결이 빨라집니다.

**S8 (280-300초)**
> 이것으로 HOMEZ V6.5 가이드 다섯 편을 모두 마칩니다. 시청해 주셔서
> 감사합니다.
