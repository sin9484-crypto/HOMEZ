# HOMEZ V6.5 문제 해결과 안전 사용 가이드 (한국어)

- 대상: 모든 역할
- 목표 재생 시간: 5~8분
- 버전: HOMEZ V6.5
- 검증 상태: `app/core/auth.py`, `app/main.py`의 제한 모드 미들웨어,
  `app/domains/diagnostics/router.py`, 그리고 실제 재현한 로그인 실패
  화면 캡처(`homez_console_token` 세션이 남아있으면 로그인 화면
  대신 이전 세션이 뜨는 실제 버그를 이 가이드 제작 중 직접 겪고
  고친 사례 포함)로 확인.

## 이 가이드에서 다루는 것 / 다루지 않는 것

**다룬다**: 실제로 발생하는 오류 화면과 그 의미, 상단 상태 배지가
빨간색일 때의 정확한 원인, 안전 사용을 위한 규칙, 지원팀에 문의할 때
도움이 되는 진단 내보내기 API(현재는 화면 버튼 없음, API로만 존재).

**다루지 않는다**: 실제 장애 대응 매뉴얼(운영 인시던트 대응은 별도
운영 문서), 실제 백업/복원 실행 절차의 상세 명령어(내부 운영자 문서
`docs/PACKAGING_CHECKLIST.md` 등 참고).

## 1. 로그인 오류

아이디 또는 비밀번호가 틀리면 서버가 401을 반환하고, 화면에는 실제로
아래처럼 표시된다.

![로그인 오류 - 아이디/비밀번호 불일치](screenshots/05_troubleshooting/01_login_wrong_password.png)

실제 오류 문구는 "아이디 또는 비밀번호가 올바르지 않습니다."이며,
어떤 값이 틀렸는지는 알려주지 않는다(계정 존재 여부를 추측하지
못하게 하려는 의도적 설계).

## 2. 상단 상태 배지가 빨간색으로 보일 때

대시보드 상단에는 V5.0.0 / 서버 연결됨 / 스키마 적용됨 / 모드 /
EStop 다섯 가지 배지가 있다. **관리자가 아닌 역할(매니저/스태프/
뷰어)로 로그인하면 이 중 스키마·모드·EStop 세 배지가 빨간색
"확인 실패"로 보인다.** 이것은 시스템 장애가 아니라, 그 정보를 조회할
권한이 없어서 발생하는 정상적인 권한 차단이다. 관리자 계정으로
로그인하면 전부 초록색으로 보인다.

## 3. "이 데이터를 볼 권한이 없습니다" 메시지

대시보드나 상품 후보 등 관리자 전용 화면을 매니저/스태프/뷰어 권한
으로 열면 이 메시지가 표시된다. 해결 방법은 관리자 계정으로 로그인
하거나, 관리자에게 해당 화면에 필요한 권한을 요청하는 것이다(가이드
2의 "사용자 관리" 참고).

## 4. 실제 오류 코드 표

| 상황 | HTTP 상태 | 코드/문구 | 의미 · 대응 |
|---|---|---|---|
| 로그인 실패 | 401 | "Invalid username or password." | 아이디/비밀번호 재확인 |
| 비활성 계정 | 401 | "Inactive user" | 관리자에게 계정 활성화 요청 |
| 권한 부족 | 403 | "Insufficient privileges" / "권한이 없습니다" | 관리자 권한 필요, 가이드 2 참고 |
| Migration 제한 모드 | 423 | `MIGRATION_RESTRICTED_MODE` | Migration이 보류 중일 때 쓰기 요청이 전역 차단됨. 관리자가 Migration을 승인해야 해제됨 |
| 판매채널 API 빈도 제한 | 429 | Retry-After 헤더 포함 | 안내된 대기 시간 이후 재시도, 화면에 카운트다운 표시 |

## 5. 안전 사용 수칙

- **초대 코드·복구 코드·API Access Key는 절대 캡처/공유하지 않는다.**
  화면 녹화나 스크린샷을 지원팀에 보낼 때도 반드시 가려야 한다.
- **Fake Provider/dry-run 화면임을 항상 인지한다.** "채널별 판매
  방식"이나 "AI 상품 등록" 화면에 나오는 경고 배너는 장식이 아니라
  실제 코드 상태를 알려주는 것이다.
- **준비 중 메뉴는 클릭해도 안전하다** — 실제로 아무 데이터도
  변경하지 않는다.
- **Migration 승인은 관리자만** 수행해야 하며, 실행 전 백업이
  선행되어야 한다(내부 운영 절차).

## 6. 지원팀에 문의할 때 — 진단 내보내기

HOMEZ에는 `GET /diagnostics/export` API가 있다. 앱 버전, OS 정보, DB
무결성 상태, Migration 상태, 등록된 라우트 수, 로그 마지막 부분(비밀
정보 제거됨)을 한 번에 모아준다. **현재 V6.5에는 이 API를 호출하는
화면 버튼이 없다** — 관리자 권한이 있는 사람이 API를 직접 호출해야
하며, 지원팀 문의 시 그 결과를 첨부하면 진단이 빨라진다.

## 포함 기능 / 제외 기능 요약

**실제 구현되어 이 가이드가 다루는 기능**: 로그인 오류 화면, 권한
차단 배지/메시지의 정확한 의미, Migration 제한 모드(423), 판매채널
API 빈도 제한(429), 진단 내보내기 API.

**존재하지 않는 것**: 진단 내보내기를 위한 화면 버튼(API만 존재).
