# HOMEZ V6.5 모바일 사용법 가이드 (한국어)

- 대상: 스마트폰/작은 화면에서 HOMEZ Console을 확인하는 모든 역할
- 목표 재생 시간: 5~8분
- 버전: HOMEZ V6.5
- 검증 상태: 실제 반응형 CSS와 `#mobile-nav-toggle` 버튼 동작을 3개
  실제 뷰포트(430×932, 390×844, 360×800)에서 캡처해 확인. Manager
  역할로 확인.

## 이 가이드에서 다루는 것 / 다루지 않는 것

**다룬다**: 모바일 화면에서 로그인, 좁은 화면에서 상단바가 어떻게
재배치되는지, 햄버거 메뉴로 좌측 메뉴 열기, 여러 화면 크기에서의
레이아웃 차이, 모바일에서도 데스크톱과 동일하게 적용되는 권한 차단.

**다루지 않는다**: HOMEZ에는 별도의 네이티브 모바일 앱이 없다 —
이 가이드는 **브라우저 반응형 레이아웃**만 다룬다. 모바일 전용
기능(푸시 알림 등)은 존재하지 않는다.

## 1. 모바일 로그인 화면

430×932 뷰포트에서도 로그인 화면 레이아웃은 데스크톱과 동일한 카드
구조를 유지하며, 좁은 화면에 맞게 폭이 줄어든다.

![모바일 로그인 화면](screenshots/04_mobile/00_login_430x932.png)

## 2. 로그인 후 — 상단바가 좁아진다

로그인 후 화면 폭이 좁아지면 좌측 메뉴가 기본적으로 숨겨지고, 대신
상단바 왼쪽에 햄버거 아이콘(☰)이 나타난다. 검색창과 상태 배지는 그대로
유지되지만 줄바꿈되어 배치된다.

![대시보드 - 430x932](screenshots/04_mobile/01_dashboard_430x932.png)

## 3. 햄버거 메뉴로 좌측 메뉴 열기

상단바의 ☰ 아이콘을 누르면 데스크톱과 동일한 좌측 메뉴 전체가 화면
위로 슬라이드되어 나타난다(같은 6개 그룹, 같은 "준비 중" 배지 포함).

![모바일 메뉴 열림](screenshots/04_mobile/03_nav_drawer_open_430x932.png)

## 4. 화면 크기별 비교

같은 계정, 같은 대시보드 화면을 세 가지 실제 뷰포트에서 확인했다.

| 뷰포트 | 화면 |
|---|---|
| 430×932 | ![430x932](screenshots/04_mobile/01_dashboard_430x932.png) |
| 390×844 | ![390x844](screenshots/04_mobile/01_dashboard_390x844.png) |
| 360×800 | ![360x800](screenshots/04_mobile/01_dashboard_360x800.png) |

세 화면 모두 카드가 세로로 쌓이는 1열 레이아웃을 유지하며 잘리거나
겹치는 요소 없이 정상적으로 표시된다.

## 5. 모바일에서도 동일하게 적용되는 권한 차단

Manager 역할로 모바일에서 상품 후보 화면에 들어가면, 데스크톱과
동일하게 "이 데이터를 볼 권한이 없습니다(관리자 권한 필요)"가 그대로
표시된다 — 화면 크기와 무관하게 서버 권한 검사가 동일하게 적용됨을
보여준다.

![모바일 상품 후보 - 권한 차단](screenshots/04_mobile/02_candidates_430x932.png)

## 포함 기능 / 제외 기능 요약

**실제 구현되어 이 가이드가 다루는 기능**: 모바일 반응형 로그인,
햄버거 메뉴, 3개 뷰포트에서의 레이아웃, 모바일에서도 동일한 권한
차단.

**존재하지 않는 기능**: 네이티브 모바일 앱, 푸시 알림, 모바일
전용 단축 기능.
