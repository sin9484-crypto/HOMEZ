# HOMEZ V6.5 가이드 — 기능 포함/제외 통합 목록

5개 가이드 전체에서 "실제 기능으로 설명한 것"과 "화면에 보이지만
아직 실제 기능이 아닌 것"을 한곳에 모은다. 개별 가이드 문서의 해당
섹션에서 발췌·정리한 것이며, 출처는 각 가이드 문서를 따른다.

## 실제 구현되어 가이드가 다루는 기능 (V6.5 완료)

| 영역 | 기능 | 근거 가이드 |
|---|---|---|
| 인증 | 로그인, 로그인 전/후 언어 전환 | 1 |
| 인증 | 회원가입(가입 신청) + 관리자 승인 대기열 | 2 |
| 인증 | 초대 코드 발급 | 2 |
| 인증 | 사용자 관리(역할 변경/비활성화/비밀번호 재설정 시작/새 사용자 추가) | 2 |
| 계정 | 비밀번호 변경, 세션 폐기, 복구 코드 생성 | 2 |
| 대시보드 | 역할별 접근 제어(super_admin/admin/manager/staff/viewer) | 1, 4 |
| 상품 | 상품 후보 목록/필터 | 3 |
| 상품 | 상품등록 통합 마법사 1단계(ProductCandidate ID 입력) | 3 |
| 채널 | 판매채널 연동 화면(Credential 입력 UI까지) | 2 |
| 채널 | 채널별 판매 방식 선택 화면 진입 | 3 |
| 모바일 | 반응형 로그인/대시보드/메뉴, 햄버거 드로어 | 4 |
| 오류 처리 | 로그인 실패(401), 권한 부족(403), Migration 제한 모드(423), API 빈도 제한(429) | 5 |
| 운영 | 진단 내보내기 API(`GET /diagnostics/export`, 화면 버튼 없음) | 5 |

## 화면에 등장하지만 Fake Provider/dry-run/미완성인 것

| 영역 | 실제 상태 | 근거 가이드 |
|---|---|---|
| 판매채널 연동 | "절차 안내 예시" 배너 — 실제 판매자센터 화면과 다를 수 있음, 실제 Access Key 미저장 | 2 |
| 채널별 판매 방식 | `LIVE_E2E_PENDING_USER_CREDENTIAL` 배너 — 실제 쿠팡/네이버 전송 코드 없음 | 3 |
| 상품등록 통합 마법사 2~10단계 | 코드(`i18n` 카탈로그, `listing_wizard_*.py`)로만 확인, 실제 화면 캡처는 1단계까지만 진행 | 3 |
| AI 상품 등록(이미지) | Fake Provider 전용, 최종 제출은 항상 dry-run(Gate X-1/X-5 문서 근거) | 3(언급) |

## 좌측 메뉴의 "준비 중" 항목 (7개, 완전히 비활성)

상품 목록, 주문 현황, 배송, 반품·교환, 키워드 분석, 마진·수익 분석,
채널 정산 — 클릭해도 안내 문구만 나오며 데이터를 변경하지 않는다.
(가이드 1, 5절 참고)

## V7 예정이라 V6.5 가이드에서 다루지 않은 것

- 실제 쿠팡/네이버 API 연동 완료(실제 판매자 계정으로 실제 상품 등록)
- 실제 AI 이미지 생성 API 연동
- 실제 결제/정산 흐름
- 실제 이메일/SMS 발송
- 네이티브 모바일 앱

## 영상 제작 관련 제약

Desktop/Mobile MP4는 이 환경에 영상 녹화·인코딩 도구가 없어 아직
제작되지 않았다. 스토리보드·내레이션 대본·자막·실 화면 캡처는 5개
가이드 전부 완성되어 있다. 자세한 내용은
[GUIDE_INDEX.md](GUIDE_INDEX.md)의 "영상" 절 참고.
