# 앱 내부 도움말 요약 — 모바일 사용법

## 한국어

**메뉴가 안 보여요**: 화면이 좁으면 좌측 메뉴가 자동으로 숨겨집니다.
상단 왼쪽의 ☰ 아이콘을 누르세요.

**네이티브 앱이 있나요**: 아니요. HOMEZ는 브라우저 반응형 화면으로
모바일을 지원하며, 별도 설치형 앱은 없습니다.

**모바일에서 권한이 다른가요**: 아니요. 서버가 권한을 검사하므로
데스크톱과 모바일에서 동일하게 적용됩니다.

## English

**I can't see the menu**: on a narrow screen the left menu is hidden
automatically. Tap the ☰ icon at the top left.

**Is there a native app?**: no. HOMEZ supports mobile through a
responsive browser layout only — there is no separate installable
app.

**Are permissions different on mobile?**: no. Permissions are
enforced server-side, so they apply identically on desktop and
mobile.
