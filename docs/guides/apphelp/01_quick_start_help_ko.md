# 앱 내부 도움말 요약 — 빠른 시작

## 한국어

**로그인**: 아이디·비밀번호 입력 후 로그인 버튼을 누르세요. 로그인
화면 우측 상단에서 언어를 바꿀 수 있습니다.

**로그인 후 화면**: 왼쪽 메뉴에서 원하는 기능으로 이동하세요.
"준비 중" 표시가 붙은 메뉴는 아직 사용할 수 없습니다.

**언어 변경**: 로그인 후에는 설정 · 계정 및 보안 화면에서만 언어를
바꿀 수 있습니다.

**권한에 따라 다른 화면**: 매니저·스태프·뷰어 계정은 관리자 전용
데이터에 접근할 수 없습니다. "권한 없음" 안내가 뜨면 관리자 계정으로
로그인하거나 관리자에게 권한을 요청하세요.

## English

**Login**: Enter your username and password, then press the login
button. You can switch language from the top-right of the login
screen.

**After login**: Use the left menu to navigate. Items marked "Coming
soon" are not usable yet.

**Changing language**: After login, language can only be changed
from the Settings · Account & Security screen.

**Role-based screens**: Manager/Staff/Viewer accounts cannot access
admin-only data. If you see "Permission denied," sign in as an admin
or ask an admin to grant access.
