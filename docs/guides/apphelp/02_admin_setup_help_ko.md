# 앱 내부 도움말 요약 — 관리자 초기 설정

## 한국어

**팀원 초대**: 설정 · 계정 및 보안 화면에서 초대 코드를 발급하거나,
사용자 관리에서 새 사용자를 직접 추가하세요.

**가입 승인**: 초대 코드 없이 가입한 신청은 "가입 승인 대기"
목록에서 관리자가 직접 승인/거절해야 이용할 수 있습니다.

**판매채널 연동**: 실제 쿠팡/네이버 계정 정보를 입력하기 전에 안내
배너를 꼭 읽어보세요 — 절차는 참고용이며 실제 판매자센터 화면과
다를 수 있습니다.

**복구 코드**: 로그아웃 상태에서 비밀번호를 스스로 재설정하려면
미리 복구 코드를 생성해 안전하게 보관하세요. 코드는 생성 시 한 번만
표시됩니다.

## English

**Inviting teammates**: issue an invite code from Settings · Account
& Security, or add a new user directly from user management.

**Approving sign-ups**: requests submitted without an invite code
must be approved or rejected by an admin in the "Pending sign-up
approvals" list before they can be used.

**Store Connection**: read the banner before entering any real
Coupang/Naver account information — the procedure shown is a
reference and may differ from the actual seller-center screens.

**Recovery codes**: generate and safely store recovery codes ahead of
time if you want to be able to reset your own password while logged
out. Codes are shown only once, at generation time.
