# 앱 내부 도움말 요약 — 상품 등록 전체 과정

## 한국어

**시작하는 법**: 상품 후보 목록에서 승인(APPROVED)된 후보를 확인한
뒤, 상품등록 통합 마법사에서 "새 마법사 시작"을 누르고 후보 ID를
입력하세요.

**10단계 구조**: 상품 소스 → 초안 → 이미지 → 판매채널 → 판매 방식 →
가격·마진 → 사전검사 → 승인 → 실행 선택 → 결과. 실제 등록은 8단계
승인을 통과해야만 9단계에서 실행됩니다.

**승인은 왜 별도로 필요한가요**: 요청한 사람이 스스로 승인할 수
없습니다. 다른 승인 권한자가 승인해야 하며, 승인 후 가격이나 수량이
바뀌면 승인이 자동으로 무효화됩니다.

## English

**Getting started**: check the Product Candidates list for an
APPROVED candidate, then press "Start new wizard" in the Listing
Wizard and enter that candidate's ID.

**The 10 steps**: Product Source → Draft → Media → Channels →
Fulfillment → Pricing & Margin → Precheck → Approval → Execution
choice → Results. Real registration only executes at step 9, after
step 8 approval.

**Why is approval separate?**: the requester cannot approve their own
request. A different approver must approve it, and the approval is
automatically invalidated if price or quantity changes afterward.
