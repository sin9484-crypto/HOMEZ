# HOMEZ V7 필수 작업 범위

- 확정일: 2026-08-30
- 상태: 사용자 확정 기준
- 목적: V7 개발 우선순위와 완료 판정의 기준을 고정한다.
- **추가 기록(2026-09-07)**: 아래 "6. 자동 매입" 항목의 목표·설계
  기준을 사용자가 상세화했다 — `docs/HOMEZ_V7_INTEGRATED_
  PROCUREMENT_GOALS_20260907.md` 참고. 이 문서의 작업 순서·범위
  자체는 바뀌지 않았고, "자동 매입" 단계 안에서 더 구체적인 목표가
  추가됐을 뿐이다.

## 필수 작업

1. 쿠팡 상품등록 안정화
   - 실제 등록 오류·경고, 필수값, 브랜드, 상태 조회, 중복 방지,
     HOMEZ 제출 원장 연결을 완성한다.
2. DB·데이터 안정화
   - canonical DB 경로, 경로 리디렉션, Migration, 백업·복원,
     설치·업데이트 데이터 보존을 검증한다.
3. 상품 발굴·추천 AI
   - 공식 Provider 연합검색, 동일상품 판별, 수요·경쟁·가격·마진·위험
     분석과 근거 있는 추천을 구현한다.
4. 이미지 생성 AI 개발
   - 이미지 입력·분석, 누끼, 배경 생성, 합성, 자동 배치, 사실 기반
     문구, 다중 시안, 부분 재생성, 수동 편집 전환, 채널 규격 검사와
     버전 저장을 구현한다.
5. 주문 수집
   - 쿠팡 주문 자동 수집, 중복 방지, 주문 정규화, 상태 원장과 실제
     주문 Live 검증을 완성한다.
6. 자동 매입
   - 주문·상품 매칭, 가격·옵션·수량·배송지 재검증, 전용 브라우저,
     일괄 처리, 예외 큐, 중복 결제 방지와 실제 소액 매입 검증을
     완성한다.
7. 배송·취소·반품
   - 송장, 배송 동기화, 취소·반품·교환·회수·환불 상태와 불일치
     복구를 구현한다.
8. 정산·손익
   - 정산 예정액·실입금, 매출·매입·배송비·수수료, 예상·실제이익과
     정산 이상 탐지를 구현한다.
9. 로그인·운영 안전
   - HOMEZ 세션 자동 갱신, 매입처 세션 분리, Credential 상태 정합성,
     개인정보 마스킹, 중복 실행·결제 차단, 핵심 승인과 감사로그를
     완성한다.
10. 출시 검증
    - 집중·전체 회귀, 격리 브라우저 E2E, 반응형 UI, Migration
      리허설, 공식 패키징, 재설치·업데이트 데이터 보존 및 실제 거래
      흐름을 검증한다.

## 작업 순서

```text
상품등록 안정화
→ DB 기준 확정
→ 주문 수집
→ 자동 매입
→ 배송·취소·반품
→ 정산·손익
→ 상품 발굴·추천 AI
→ 이미지 생성 AI
→ 전체 회귀·패키징·실제 운영 검증
```

## 완료 원칙

- 버튼·화면·Fake Provider만 존재하는 상태를 기능 완료로 보지 않는다.
- 실제 업무가 처음부터 끝까지 수행되고 결과가 원장에 남아야 한다.
- 격리 검증, 공식 설치본 반영, Live 검증을 구분해 보고한다.
- `V7_RELEASE_READY`는 위 필수 흐름과 출시 검증이 모두 충족된 뒤에만
  선언한다.
