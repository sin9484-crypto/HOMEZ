## 6. 신규 기능: URL로 상품 가져오기 (2026-10-14)

쿠팡 실등록을 반복하며 가장 시간이 걸린 부분(상품 정보를 사람이 옮겨 적기)을 줄이기 위한 기능이다.
흐름: **입력창에 URL → URL 검색 → 기재 내용 복사 → 수익 계산 → 상품 등록(초안 생성)**.

| 항목 | 내용 |
|---|---|
| 위치 | 상품 등록 화면의 "URL로 가져오기" 버튼 → `lw-url-import-panel` |
| API | `POST /product-import/search`, `/margin-proposal`, `/create-draft` (권한: `listing_wizard.create`) |
| 코드 | `app/domains/product_import/` (`html_tree`, `generic_extractor`, `onchannel_page`, `service`, `router`, `schema`) |
| 지원 | 온채널(공개 페이지 + 공식 API로 가격·옵션·배송비) + 일반 페이지(JSON-LD·OG·표, best-effort) |
| 재사용 | SSRF 방어 페이지 읽기(`media_asset/url_import.py`), 이미지 가져오기·긴 이미지 분할, `margin_calculator`, 후보·위저드 서비스 |
