## 4. 운영·절차에서 배운 점

| # | 문제 | 교훈·조치 |
|---|---|---|
| P1 | **백업 3건(restart9~11)이 앱이 쓰지 않는 설치 폴더 DB를 복사** | 앱의 실제 DB는 저장소의 `homez.db`. 백업 전에 경로·수정 시각을 확인하고 백업 안에서 최신 행(예: 최신 제출)을 읽어 검증한다. 올바른 백업: restart8(10-12), unknown12_resolve, restart12(10-14). |
| P2 | 8단계 승인과 전송이 연쇄되어 POST 예산 0에서 결과불명 2회(제출 #8·#9, #12) | **POST 예산은 8단계 승인 전에 열고**, 확인용 GET 1회도 같이 연다(`budget 1 1 0`). 전송 직후 0으로 닫는다. |
| P3 | 승인 요청에서 호출 종류를 GET으로 잘못 안내(브랜드 검색은 POST) | 승인 요청 전에 소스에서 메서드·횟수를 확인한다. |
| P4 | 자동 안전 검사가 POST 예산 열기, 가드 완화, DB 정정을 거부 | 우회하지 않고 사용자 허용 규칙·명시 승인을 받는다. |
| P5 | 가드에 R2 접미사 허용을 임시 추가 | 이미지 업로드 한 번만 쓰고 재시작 때 원래 설정으로 되돌림. |
| P6 | 앱 재시작마다 로그인 재요청 | 재시작은 코드 변경이 필요한 때만, 한 번에 묶는다. |
| P7 | 가드 로그에 `CHILD_UNGUARDED (cmd.exe)` 신규 기록 | 네트워크 관련 아님으로 보이나 계속 관찰. |
| P8 | 가드 로그는 앱을 다시 켤 때마다 새로 쓰여 이전 실행의 호출 기록이 사라짐 | 재시작 전에 로그를 보관 폴더로 복사한다(호출 누계 재구성에 필요했음). 미구현(런처 수정). |
