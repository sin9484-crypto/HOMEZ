## 2. 정정(내 이전 보고의 오류)

- 이전 기록(위저드 #22 전송 결과 항목)에 "제출 단계가 쿠팡 전송까지 이어짐"이라고 적은 것은 **틀렸다.** 확인 결과 제출 #19의 생성은 05:09:50 UTC, 쿠팡 POST는 05:10:14 UTC(24초 뒤), 감사 `COUPANG_PRODUCT_SUBMISSION_SUBMITTED`는 05:10:16이다 — 사용자가 제출 직후 결과 화면의 "쿠팡으로 전송"을 따로 눌렀다. 제출과 전송은 다른 단계이고, 전송은 계속 전송 전 검사와 비밀번호 재확인 뒤에만 일어난다.
- 이전 보고의 "정산 조회가 14시간 멈춤"은 DB 시각(UTC)을 한국 시각으로 잘못 읽은 것이었다(실제 마지막 정산 조회는 11:56 KST, 정상).

## 3. 하지 않은 것(범위 밖, 별도 승인 사항)

- 개발용 범위 한정 가드(저장소 밖) 자체는 바꾸지 않았다. 가드 규칙 만료는 사용자가 승인한 연장(48시간)으로 처리했다.
- 쿠팡·온채널로 나가는 새 호출은 없다(A 단계는 읽기·승인 흐름 개선만).
- Migration 없음(허용 연장은 기존 표에 새 행 추가).
