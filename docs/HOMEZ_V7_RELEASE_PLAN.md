2. **exe 헬스체크 타임아웃 재현 확인**(실제 대화형 Windows PC).
   재현 시 `HEALTH_TIMEOUT_SECONDS` 조정.
3. **설치 프로그램 도구 선정 + 실제 설치 프로그램 빌드**(Inno Setup
   등, Live Gate).
4. **Permission 모델 드리프트 수정 여부 결정**(B절 참고).
5. 위 4가지가 끝나면 실제 클린 PC에서 설치→실행→로그인→핵심 기능
   1회씩 수동 확인(최종 스모크).

## 5. 사용자 가이드/영상 준비 상태

V7 Gate 0~10 어디에서도 최종 사용자용 가이드 문서나 영상 제작은
범위에 포함되지 않았다(전부 엔지니어링/검증 작업). 콘솔 UI 자체에
"가이드"/"투어" 기능이 이미 존재함을 Gate 10 Browser 세션에서 확인
(nav의 "가이드" 항목, 로그인 화면과 무관하게 항상 visible) — 이
내장 가이드 기능의 콘텐츠가 V7 신규 도메인(재고/주문/발주/배송/반품/
가격/정산)까지 다루는지는 이번 세션에서 확인하지 않았다(범위 밖).
**Live-Input 필요**: 실사용자 대상 가이드 문서/영상은 별도 콘텐츠
제작 작업으로 진행 필요.
