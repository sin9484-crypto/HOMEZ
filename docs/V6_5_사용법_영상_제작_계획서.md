# HOMEZ V6.5 사용법 영상 제작 계획서 (Gate Z-5, 2026-08-12)

- 상태: 계획만 작성. 실제 촬영/편집/녹화는 하지 않았다(이 세션은
  화면 녹화·영상 편집 도구를 실행할 수 없고, 실제 배포 실행 파일
  자체가 아직 없다 — `docs/V7_LIVE_GATE_PLAN.md` F절).
- 목적: HOMEZ Desktop을 처음 쓰는 사업자가 5개 핵심 흐름을 스스로
  따라할 수 있게 하는 짧은 영상 시리즈의 시나리오를 미리 확정해,
  실제 배포 시점(V7)에 촬영만 하면 되도록 준비한다.

## 전제 조건 (촬영 시작 전 확인)

- 실제 서명된 `Homez.exe` 설치 파일이 존재해야 한다(`docs/
  PACKAGING_CHECKLIST.md` 완료 후).
- 촬영용 회사 계정은 실제 사업자 데이터가 아니라 **시연 전용
  더미 데이터**로 만든다(상호명·사업자번호·상품 정보 전부 가상).
- 화면에 실제 비밀번호·API 키·Credential이 노출되지 않도록
  녹화 전 반드시 진단 내보내기(`GET /diagnostics/export`)와
  동일한 원칙으로 화면을 스스로 점검한다.

## 영상 시리즈 구성 (5편, 각 3~6분)

### 1편 — 설치와 최초 실행

- 설치 프로그램 실행 → 최초 실행 시 "회사 정보 + 관리자 계정"
  설정 화면.
- 로그인 후 첫 화면(Overview)이 보이는 이유(역할별 첫 진입
  메뉴, Gate X-3의 `firstVisibleNavView()` 동작을 사용자 언어로
  설명 — "관리자가 아니면 개요 화면 대신 실제로 쓸 수 있는 첫
  메뉴로 바로 이동합니다").
- 언어 전환(ko-KR/en-US) 시연.

### 2편 — 상품 후보부터 마켓 등록까지

- 상품 후보 등록 → AI 판단 → 승인 → Listing Wizard 10단계 →
  마켓별 판매 방식 선택 → 제출.
- 자동저장·충돌 감지 UI가 실제로 뜨는 상황을 의도적으로
  재현(같은 초안을 다른 탭에서 동시에 열어 보여주기).
- CSV 내보내기 버튼 시연.

### 3편 — 판매채널 연결

- 쿠팡/네이버 Credential 입력 마법사(입력 화면만 시연 — 실제
  Credential 값은 절대 화면에 노출하지 않는다, 시연용 더미 값
  사용).
- 연결 검증 성공/실패 화면 각각.
- Credential 교체(rotate)와 연결 비활성화의 차이 설명.

### 4편 — 운영 화면(백업/알림/진단) — Gate Y 신규 기능

- 설정 > 백업에서 "지금 백업" 버튼 → 백업 이력에 새 행이 생기는
  것 확인.
- 알림 아이콘 클릭 → 안 읽은 알림 배지가 줄어드는 것 확인.
- 진단 내보내기 버튼 → 다운로드된 파일을 열어 "비밀번호나 API
  키가 전혀 없다"는 것을 직접 보여주며 안심시키기(고객지원에
  이 파일을 보내도 안전하다는 메시지 전달).

### 5편 — 문제가 생겼을 때

- 네트워크 오류 시 로그아웃되지 않는다는 것(재로그인 요구 X)을
  실제로 네트워크를 끊어서 보여주기.
- 인증 만료 시에만 로그인 화면으로 이동한다는 것 대비 시연.
- 실패한 등록 재시도 버튼.
- 진단 내보내기 결과를 고객지원에 보내는 방법 안내로 마무리.

## 촬영 형식

- 해상도: 1920×1080, Desktop 프리셋 기준(반응형 확인용 별도
  숏은 1366×768 1개만 추가).
- 자막: ko-KR 기본, en-US 버전은 언어 전환 후 동일 스크립트
  재촬영(더빙이 아니라 UI 자체가 바뀌는 것을 보여주는 것이
  중요하므로).
- 마우스 클릭 시 시각적 강조(클릭 위치 원형 하이라이트) 필요 —
  편집 단계에서 추가.

## 스크립트 작성 시 지켜야 할 것

- "자동으로 ~됩니다" 같은 표현은 실제로 자동인 기능에만 쓴다
  (예: 백업은 "지금 백업" 버튼을 눌러야 하는 수동 기능이므로
  "자동 백업"이라고 말하면 안 된다 — `docs/HOMEZ_OPERATIONS_
  REPORT.md`와 일치시킨다).
- V7에서 처음 생기는 기능(자동 업데이트, 실제 결제 등)을 지금
  있는 것처럼 보여주지 않는다.

## 다음 단계 (V7)

1. 실제 서명된 설치 파일 확보(`docs/PACKAGING_CHECKLIST.md`).
2. 시연용 더미 회사 데이터 세팅 스크립트 작성.

4. 게시 후 `app/domains/update`의 공지에 영상 링크를 `release_
