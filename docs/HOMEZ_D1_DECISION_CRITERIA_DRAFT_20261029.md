# D1 — 의사결정 AI 평가 기준 초안 v1 (2026-10-29)

이 문서는 통합 AI 계획(`docs/HOMEZ_CORE_AI_STATUS_20261029.md`) 0단계의 D1 결정 초안이다.
- **숫자는 사용자 확정 전까지 초안이다.** 확정하면 이 값으로 평가 정책(VERIFIED)을 등록하고 1단계(실제 첫 평가)를 진행한다.
- 초안을 만들면서 평가기 자체의 결함을 찾아 고쳤다(평가기 1.1.0, 6장).
- 대상 사업 전제: 무재고 중개(공급처 직송)·쿠팡 판매. 돈(마진)·판매 금지·상표권·공급 중단이 가장 큰 손실 원인이다.

## 1. 한눈에 보기

| 항목 | 초안 값 |
|---|---|
| 승인 추천 최소 총점 | **70점** (100점 만점) |
| 보류 추천 | 50점 이상 70점 미만 |
| 직접 검토 필요 | 30점 이상 50점 미만 |
| 거절 추천 | 30점 미만 |
| 최소 신뢰도 | **0.60** (현재 기본 0.50에서 올림) |
| 근거 있는 항목 비중 | **70% 이상**이어야 판정(미만이면 데이터 부족) |
| 승인 추천 필수 근거 | 마진·정책·상표·공급 4개 항목 모두 |
| 점수와 무관하게 사람 검토 | 정책 안전도 40점 미만 / 상표 안전도 40점 미만 / 예상 마진율 < 회사 최소 목표 마진율(기본 18%) / 필요 자금 > 가용 자금 |
| 최종 결정 | 항상 사람(승인·보류·거절·덮어쓰기). AI 추천만으로 상태가 바뀌지 않는다 |

## 2. 항목별 비중 (12개, 합계 1.00)

점수는 모두 0~100이고 높을수록 좋다(위험 항목은 '안전할수록 높음'으로 통일).

| 항목 | 무엇을 보나 | 비중 | 필수 | 이유 | 근거 자료 |
|---|---|---|---|---|---|
| 마진·수수료 | 수수료·배송비 뺀 예상 마진율 | **0.20** | ✅ | 무재고라 재고 손실은 없지만 건당 이익이 사업의 전부 | 마진 분석(URL 분석)의 마진율 — 자동 제안 / 사람 입력 |
| 정책·금지상품 | 쿠팡 판매 금지·효능 표현·규제 분류·KC | **0.12** | ✅ | 걸리면 판매 정지·계정 제재 | 후보 사전 평가(S2) — 자동 제안 |
| 상표·지식재산 | 상표 단어·브랜드 판매 권리 | **0.12** | ✅ | 권리 침해 신고는 즉시 판매 중단·분쟁 | S2 상표 단어 — 자동 제안(단어 검사뿐) |
| 공급 안정성 | 공급처 품절·단종·가격 변동 | **0.12** | ✅ | 직송이라 공급처 품절 = 주문 취소·패널티 | 사람 입력(공급처 재고 이력 연결은 다음 개선) |
| 수요·트렌드 | 검색 추세(네이버) | 0.10 | | 팔릴지의 1차 신호 | 트렌드 AI 점수(0~1을 0~100으로) |
| 반품·클레임 위험 | 사이즈·불량·오배송 반품 가능성 | 0.08 | | 반품비·회수 비용이 마진을 깎음 | 사람 입력(반품 이력 연결은 다음 개선) |
| 가격 경쟁력 | 같은 상품 대비 판매가 위치 | 0.07 | | 비싸면 안 팔림 | 사람 입력 |
| 경쟁 강도 | 판매자 수·검색 경쟁 | 0.06 | | 초보 판매자에게 과열 시장 불리 | 후보 점수(있을 때) |
| 재고·배송 위험 | 출고 지연·파손 위험 | 0.05 | | 배송 지연은 판매자 점수에 영향 | 사람 입력 |
| 매출 가능성 | 예상 월매출 | 0.04 | | 환산이 거칠어(아래 4장) 비중을 낮게 | 사람 입력 |
| 자금 영향 | 필요 자금 대비 가용 자금 | 0.02 | | 무재고라 선매입 자금이 작음(부족하면 따로 차단) | 사람 입력 |
| 데이터 신뢰도 | 후보 근거의 신뢰도 | 0.02 | | 신뢰도는 따로 판정 기준(0.60)이 있어 비중은 최소 | 후보 신뢰도 |

- 필수 4개의 비중 합은 0.56이다. 근거 비중 70%를 넘으려면 나머지에서 0.14 이상이 더 필요하다. 예: 수요(0.10) + 반품(0.08).
- 현재 시험용 정책 비중(시험 코드 `FULL_WEIGHTS`)과 다른 점:
  - 마진을 0.15에서 0.20으로, 상표를 0.05에서 0.12로, 공급을 0.08에서 0.12로 올렸다.
  - 매출을 0.12에서 0.04로, 자금을 0.05에서 0.02로 내렸다.
  - 이유는 위 표와 같다.

## 3. 판정 순서 (평가기 1.1.0 실제 순서)

1. 긴급 중지가 켜져 있으면 평가하지 않는다. 사용 가능한 평가 정책이 없어도 평가하지 않는다.
2. 근거 있는 항목이 6개 미만이면 **데이터 부족**이다.
3. 근거 있는 항목의 비중 합이 70% 미만이면 **데이터 부족**이다.
4. 차단 항목에 하나라도 걸리면 **검토 필요**다(점수로 상쇄하지 않는다). 걸린 항목 이름을 사유로 적는다.
   - 정책 안전도 40점 미만
   - 상표 안전도 40점 미만
   - 예상 마진율이 회사 최소 목표 마진율 미만
   - 필요 자금이 가용 자금보다 많음
5. 신뢰도가 0.60 미만이면 **데이터 부족**이다.
6. 총점 70점 이상이면 **승인 추천**이다. 다만 필수 4항목 중 근거 없는 것이 있으면 **보류 추천**이고, 빠진 항목을 사유로 적는다.
7. 총점 50점 이상이면 보류 추천, 30점 이상이면 검토 필요, 그 아래는 거절 추천이다.

**총점** = 근거 있는 항목들의 (점수 × 비중) 합 ÷ 근거 있는 항목들의 비중 합.

## 4. 점수로 바꾸는 규칙

| 입력 | 환산 |
|---|---|
| 예상 마진율 | 마진율 × 400 (25% 이상이면 100점, 18%면 72점, 10%면 40점) |
| 후보 점수(트렌드·수요·경쟁·마진·위험) | 0~1 값 × 100 (위험은 100에서 뺌) |
| 사람 입력 점수(공급·배송·반품·가격·상표·정책) | 0~100 그대로 |
| 예상 매출 | 원 ÷ 1,000 (10만 원 이상이면 100점) — 거칠어서 비중을 0.04로 낮춤 |
| 자금 | 가용 ≥ 필요면 100점, 부족하면 부족 비율만큼 깎고 차단 |

## 5. 자동 입력 제안 (후보 사전 평가 → 숫자)

`GET /decisions/candidates/{id}/suggested-inputs`가 **제안만** 한다. 저장하지 않고 평가도 실행하지 않는다. 사용자가 보고 고친 뒤 평가를 요청한다.

| 사전 평가 결과 | 제안 값 |
|---|---|
| 금지 품목 표현 | 정책 안전도 **0** (차단) |
| 효능·아동 표현, 규제 분류(화장품·식품·의료기기·전기·어린이), KC 인증 | 정책 안전도 **50** |
| 걸린 것 없음 + 고시 근거 있음 | 정책 안전도 **90** |
| 고시 근거 없음 / 사전 평가 없음 | 제안 안 함(모름) |
| 고위험 상표 단어 | 상표 안전도 **30** (차단) |
| 상표 단어 없음 | 상표 안전도 **70**. 단어 검사일 뿐 권리 확인이 아니라 만점을 주지 않는다 |
| 마진 분석 '후보 가능' + 판매가별 마진율 | 첫 시나리오의 마진율 |
| 마진 분석 없음·보류·비추천 | 제안 안 함 |
| 공급·배송·반품·가격·매출·자금 | 근거 자료가 없어 제안 안 함(사람 입력) |

## 6. 이번에 고친 것 (평가기 1.0.0 → 1.1.0)

| # | 결함 | 영향 | 수정 |
|---|---|---|---|
| 1 | **점수 범위 불일치**: 후보 점수는 화면·트렌드 AI·신제품 AI 모두 0~1인데 의사결정 AI만 0~100으로 읽었다 | 실제 트렌드 0.8이 0.8점/100점으로 계산돼 수요 항목이 사실상 0점. 시험도 0~100 값을 넣어 숨어 있었다 | 0~1로 읽어 ×100. 0~100 값이 오면 추측하지 않고 오류. 시험 자료를 실제 범위로 맞춤 |
| 2 | **근거 없는 항목을 0점으로 더함** | '모름'이 '나쁨'이 되고, 무거운 항목이 비면 좋은 후보도 70점에 닿을 수 없었다 | 근거 있는 항목의 비중으로 나눠 총점을 낸다. 대신 근거 비중 70% 미만이면 데이터 부족 |
| 3 | **필수 근거 없이 승인 추천 가능** | 마진·공급을 모르는 채 승인 추천이 나올 수 있었다 | 마진·정책·상표·공급 근거가 모두 있어야 승인 추천. 없으면 보류 추천 |
| 4 | **마진 하한 없음** | 마진율이 낮아도 다른 점수가 높으면 승인 추천 | 회사 최소 목표 마진율(설정, 기본 18%) 미만이면 검토 필요 |
| 5 | **검토 사유 오기** | 자금 부족도 "정책·금지상품 위험"이라고 적혔다 | 실제로 걸린 항목(정책·상표·마진·자금) 이름으로 사유를 쓴다 |
| 6 | **정책 항목 자료원이 없었다** | 실제 후보는 위험 점수가 비어 있어 정책 항목이 늘 '모름' | 보강 입력 `policy_prohibited_score` 추가(후보 위험 점수가 있으면 그쪽이 우선) + 사전 평가에서 자동 제안 |
| 7 | **상표 위험 차단 없음** | 고위험 상표 단어(상표 30점)도 다른 점수가 좋으면 승인 추천(예시 계산 70.25점) | 상표 안전도 40점 미만도 검토 필요로 차단 |

- 평가 기록에 평가기 버전 `1.1.0`과 그때 쓴 최소 마진율을 남긴다. 입력이 달라지면 지문(fingerprint)도 달라진다.
- 바꾸지 않은 것: 긴급 중지 최우선, 정책 없으면 평가 안 함, 사람 승인 필수, 멱등·동시성·회사 격리, Decimal 계산.

## 7. 계산 예시

예시 상품: 마진율 22%(88점), 정책 90, 상표 70, 공급 80, 트렌드 0.6(60점), 반품 70, 경쟁 0.5(50점). 나머지는 모름.
- 근거 비중: 0.20 + 0.12 + 0.12 + 0.12 + 0.10 + 0.08 + 0.06 = **0.80** (70% 이상이라 통과)
- 총점: (17.6 + 10.8 + 8.4 + 9.6 + 6.0 + 5.6 + 3.0) ÷ 0.80 = **76.25** → 필수 4항목이 모두 있어 **승인 추천**(최종 결정은 사람)
- 같은 상품에 고위험 상표 단어가 있으면(상표 30) 총점은 70.25지만, 상표 차단에 걸려 **검토 필요**가 된다.
- 마진율이 17%면 회사 최소 18% 미만이라 **검토 필요**가 된다.

## 8. 실제 후보 12건에 적용하면 (2026-10-29, 실제 DB 읽기 전용 확인)

- 자동 제안으로 채워지는 것은 정책 안전도와 상표 안전도뿐이다.
  - 후보 6~12번은 고시 근거가 있어 정책 안전도가 나온다. 어린이 양말(11번)은 50, 나머지는 90이다.
  - 1~5번은 고시 근거가 없어 정책 안전도도 '모름'이다.
- **12건 모두 마진 분석이 없다.** 그래서 마진(필수, 0.20)이 비고, 근거 비중이 70%에 못 미쳐 지금 평가하면 **전부 데이터 부족**이 나온다. 이것은 정직한 결과다.
- 실제 평가를 하려면 후보마다 다음이 필요하다.
  1. URL 분석의 마진 계산
  2. 공급 안정성 입력
  3. 반품 위험 또는 수요(트렌드) 중 하나 이상

## 9. 확정해 주실 것

1. 2장의 비중, 1장의 기준(70점·0.60·70%·필수 4항목·차단 4종)을 이대로 쓸지.
2. 5장의 자동 제안 숫자(정책 0/50/90, 상표 30/70)를 이대로 쓸지.
3. 확정하면: 이 값으로 회사 평가 정책을 VERIFIED로 등록한다(1단계에서 만들 '평가 기준' 화면 또는 승인된 1회 등록).
   - 그다음 마진 분석이 있는 후보 1건으로 실제 첫 평가를 한다.

## 10. 다음 개선 후보 (이번에 하지 않음)

- 이미 판매 중인 상품은 실제 주문의 마진(마진 점검 기록, 예: 백산수 18.24%)을 마진 항목 근거로 쓴다.
- 공급 안정성: 온채널 재고·품절 이력에서 자동으로 계산한다.
- 반품 위험: 쿠팡 반품 기록(반품·민원 확인)에서 자동으로 계산한다.
- 매출 환산(원 ÷ 1,000)과 판매 방식별 비용 환산(원 ÷ 100)은 상품 가격 대비 비율로 바꾸는 것이 맞다.
  - 평가 정책 값이 아니라 계산식이 바뀌는 것이라 별도로 진행한다.
- 평가 기준 화면(1단계): 지금은 API만 있다.
