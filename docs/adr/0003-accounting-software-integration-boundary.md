# ADR 0003 — 회계 소프트웨어 연동 경계 (V7 Gate 5)

- 상태: 채택됨
- 날짜: 2026-08-15
- 작성 배경: V7 Gate 5(가격/원가/마진, 가격 변경 승인, 정산 대사)
  구현 중 CTO 지시 요구사항 8 — "한국 온라인셀러 회계 소프트웨어
  연동 경계 문서화(실제 연동은 하지 않는다)".

## Context

HOMEZ는 무재고 중개·주문대행 기반 AI Commerce OS다. `app/domains/
pricing`(이번 Gate 5에서 신설)이 상품별 원가/마진을 계산하고,
`app/domains/settlement`(V2.3)가 마켓 정산금 유입을 관리하며, 이제
둘을 연결해 회사별 정산/마진 내역을 CSV로 내보낼 수 있다
(`GET /pricing/export/csv`). 한국 온라인셀러 생태계에는 이 데이터를
받아 실제 세무 신고나 장부 기장을 대신해주는 전문 회계 소프트웨어/
서비스(예: 계정관리 SaaS, 세무 대리 서비스 등 — 특정 상표명은 이
문서에서 특정하지 않는다)가 다수 존재한다.

이번 Gate 5 지시문은 "실제 연동은 하지 마라"를 명시적으로 요구했고,
CLAUDE.md Safety 규칙(무단 외부 네트워크 접근 금지)과도 정확히
일치한다. 이 문서는 HOMEZ가 어디까지 책임지고 어디서부터 범위 밖인지
경계선을 확정해, 향후 "회계 연동"을 요청받았을 때 임의로 범위를
넓히지 않도록 한다.

## Decision

| 책임 | HOMEZ 범위 | 근거 |
|---|---|---|
| 상품별 원가/배송비/수수료/광고비/세금 반영 마진 계산 | **HOMEZ 책임** | `app/domains/pricing`(margin_calculator.py 재사용) |
| 채널별 예상 vs 실제 마진 추적 | **HOMEZ 책임** | `MarginSnapshot`(EXPECTED/ACTUAL) |
| 정산 예정/완료/불일치/보류 상태 관리 | **HOMEZ 책임** | `MarketplaceSettlement.status` + `SettlementReconciliation` |
| 회사별 정산/마진 내역 CSV 내보내기 | **HOMEZ 책임(구현 완료)** | `PricingService.export_accounting_csv()`, Formula Injection 방어 포함 |
| 회사별 정산/마진 내역 XLSX 내보내기 | **HOMEZ 범위, 미구현** | 이 저장소에 스프레드시트 라이브러리 의존성이 없다 — 신규 의존성 추가는 CLAUDE.md Whitelist상 별도 승인 대상. 승인되면 CSV와 동일한 데이터 소스(`PricingService`)를 재사용해 포맷만 추가하면 된다(설계상 이미 분리돼 있음) |
| 실제 세무 신고(부가세 신고, 종합소득세 신고 등) | **범위 밖 (V10+)** | 세무 신고는 법적 책임이 수반되는 별도 전문 영역이다. HOMEZ는 신고에 필요한 "원천 데이터"(매출/수수료/원가/마진)를 정확하게 산출·내보내는 데까지만 책임진다 |
| 회계 소프트웨어와의 API 자동 연동(직접 전송) | **범위 밖 (V10+)** | 외부 네트워크 호출이 필요하며, 인증정보 관리·연동 프로토콜별 매핑 등 새로운 신뢰 경계가 생긴다. CLAUDE.md의 "무단 외부 네트워크 접근 금지"와도 직접 충돌한다 |
| 세무사/회계사 판단이 필요한 항목 분류(비용 계정과목 매핑 등) | **범위 밖** | 회계 전문 판단 영역 — HOMEZ가 임의로 계정과목을 추정하지 않는다 |

## HOMEZ가 실제로 제공하는 것 (V7 Gate 5 기준)

1. `GET /pricing/export/csv` — 회사별 `ProductPricing`(현재 가격/원가
   구성), 최근 실제 마진, 정산 대사 상태를 CSV로 내보낸다.
2. `economics_view` permission이 없는 사용자에게는 금액 컬럼 자체가
   빠진 축소 CSV가 내려간다(요구사항 7과 동일 원칙 — 값을 가리는 게
   아니라 컬럼째 제외).
3. 내보낸 CSV는 그 자체로 완결된 최종 산출물이며, HOMEZ는 이 파일이
   이후 어떤 회계 소프트웨어에 업로드되는지 알지 못하고 관여하지
   않는다 — "여기까지가 HOMEZ, 그 다음은 세무사/회계 소프트웨어"가
   이 ADR이 그리는 경계선이다.

## Consequences

- 향후 "카카오뱅크 사업자통장 자동 연동", "삼쩜삼/자비스 API 연동"
  등 구체적 요청이 들어와도, 이 ADR이 채택된 상태에서는 먼저 CTO
  승인 + 별도 Gate로 범위를 새로 확정해야 한다 — 이번 Gate 5의
  암묵적 확장으로 처리하지 않는다.
- XLSX 내보내기가 실제로 필요해지면 `openpyxl` 등 의존성 추가를
  먼저 별도 승인받고, `app/domains/pricing/csv_export.py`와 나란히
  `xlsx_export.py`를 추가하되 데이터 조립 로직(`PricingService.
  export_accounting_csv`가 이미 분리해 둔 행 dict 조립 부분)은
  재사용한다 — 계산 로직을 포맷별로 중복 구현하지 않는다.
- 실제 세무 신고 기능은 이 저장소 전체에서 앞으로도 구현하지 않는다
  (CTO 지시 요구사항 9 — 이미 범위 밖으로 명시됨). 이 ADR이 그
  결정을 문서로 고정한다.
