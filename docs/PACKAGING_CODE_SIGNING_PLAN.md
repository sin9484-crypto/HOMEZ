# HOMEZ Desktop 코드 서명 계획 (실행 보류 — 계획 문서만)

- 작성일: 2026-08-12 (Gate Y-6)
- 상태: 계획만 확정. 실제 서명은 하지 않는다 — 유료 인증서가 필요하고,
  이 세션은 결제/외부 조달을 수행할 수 없다.

## 왜 필요한가

서명되지 않은 `.exe`는 Windows SmartScreen이 기본적으로 경고를
띄운다("알 수 없는 게시자"). 사용자가 매번 "추가 정보 → 실행"을
눌러야 하고, 일부 백신은 미서명 신생 실행 파일을 더 적극적으로
검사한다(`homez.spec`에서 UPX를 끈 이유와 같은 맥락 — 오탐 표면을
줄이는 일련의 조치 중 하나).

## 인증서 종류 선택

| 종류 | 특징 | 판단 |
|---|---|---|
| OV(조직 검증) 코드 서명 인증서 | 저렴, 발급 빠름. 그러나 SmartScreen 평판이 "0"부터 시작해 초기 배포량이 적으면 여전히 경고가 뜰 수 있다(다운로드 수 누적 필요). | 초기 후보 |
| EV(확장 검증) 코드 서명 인증서 | SmartScreen 평판이 즉시 확립됨(발급 즉시 경고 없음). 발급 절차가 더 엄격(사업자 실사, 하드웨어 토큰/HSM 필수). 비용이 더 높음. | **권장** — 사용자가 매번 경고를 보는 것 자체가 HOMEZ에 대한 신뢰를 깎는다 |

권장: EV 코드 서명 인증서. 사업자등록 완료 후 발급 가능(개인
명의로는 발급 불가한 CA가 대부분).

## 서명 절차 (인증서 확보 후)

1. Windows SDK의 `signtool.exe` 사용(별도 설치 필요, 이 저장소에는
   포함하지 않는다).
2. EV 인증서는 대부분 하드웨어 토큰(USB) 또는 클라우드 HSM(Azure
   Key Vault 등)로 제공된다 — 개인키 파일을 로컬에 두는 방식이
   아니다. 따라서 서명은 **그 토큰/HSM에 접근 가능한 별도의 신뢰된
   빌드 머신**에서만 수행한다.
3. 서명 대상: `homez.spec`으로 만든 `dist/Homez/Homez.exe`
   (COLLECT의 onedir 산출물 중 실행 파일)와, 설치 프로그램을 따로
   만든다면 그 설치 프로그램(.exe/.msi)도 별도로 서명한다.
4. 타임스탬프 서버를 반드시 함께 지정한다(`/tr
   http://timestamp.digicert.com` 등, 실제 CA가 제공하는 URL로
   교체) — 타임스탬프가 없으면 인증서 만료 후 서명 자체가 무효
   처리된다.
5. 서명 후 `signtool verify /pa /v Homez.exe`로 즉시 검증한다.

## 이 저장소가 지금 갖추고 있는 것 / 갖추지 않은 것

- 갖춤: `homez.spec`(빌드 스펙), `assets/homez-app.ico`(아이콘,
  Gate F-10에서 이미 검증됨), `app/desktop/paths.py`의 frozen 경로
  분기(이번 Gate Y-6에서 재확인, 변경 없음).
- 갖추지 않음(의도적, 이번 세션 범위 밖): 실제 인증서, 서명 스크립트,
  CI/CD에서 서명을 자동화하는 파이프라인, 설치 프로그램(Inno
  Setup/WiX 등) 자체.

## 설치/제거 경로 재확인 (Gate Y-6 감사 결과)

`app/desktop/paths.py`는 이미(Gate F 시리즈에서 구현됨, 이번 Gate
Y-6에서 코드만 재확인 — 재구현하지 않음) 다음을 분리해 두었다:

- 데이터: `%LOCALAPPDATA%\HOMEZ\data`(`get_data_dir()`)
- 로그: `%LOCALAPPDATA%\HOMEZ\logs`(`get_logs_dir()`)
- 백업: `%LOCALAPPDATA%\HOMEZ\backups`(`get_backups_dir()`)
- 설정: `%LOCALAPPDATA%\HOMEZ\config`(`get_config_dir()`, 존재 확인)

전부 `is_frozen()`(즉 `sys.frozen`) 분기로만 활성화되므로, 개발
모드(이번 세션 포함)에서는 절대 이 경로를 쓰지 않는다 — 실제
설치본에서만 의미가 생긴다. **제거(언인스톨) 시 이 디렉터리들을
지울지 여부는 아직 정책으로 확정하지 않았다**(사용자 데이터
보존이 기본값이어야 한다는 원칙상, 기본 제거는 프로그램 파일만
지우고 `%LOCALAPPDATA%\HOMEZ\*`는 남기는 쪽이 안전하다고 잠정
판단 — 최종 결정은 V7에서 실제 설치 프로그램을 만들 때 확정한다).

## 다음 단계 (V7, 이번 세션 범위 밖)

1. 사업자 명의 EV 코드 서명 인증서 발급.
2. 설치 프로그램 도구 선정(Inno Setup 권장 — 무료, Windows 전용
   앱에 흔히 쓰임) 및 언인스톨 시 사용자 데이터 보존 여부 확정.
3. 신뢰된 빌드 머신에서 `pyinstaller homez.spec` → `signtool`로
   서명 → 설치 프로그램 빌드 → 설치 프로그램 서명 순으로 파이프라인
   구성.
4. 첫 배포 후 SmartScreen 평판 누적 상태 모니터링(EV라면 즉시
   해소되지만, 그래도 첫 실행 시 사용자 안내 문구를 준비해 둔다).
